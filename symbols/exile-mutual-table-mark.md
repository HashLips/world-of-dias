# Exile-Mutual Table Mark

## Name

Exile-Mutual Table Mark

## Overview

The **Exile-Mutual Table Mark** is a shared bowl oval with two facing seats—meaning *mutual table for those who left*; first bowl before interrogation.

## Meaning

Exile hospitality. Forced-Final clearance-before-soup fails harder here. Softfruit Shared-Table Joy Oval is a festival cousin; this mark is second-beginning law.

## Usage

- Exile Mutual Table cards and Sorel compact boards.
- First-bowl story chapbooks.
- Long Gate exit kits carefully.
- Strike on “prove you deserve bowl” stamps.
