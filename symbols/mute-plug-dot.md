# Mute-Plug Dot

Mute-Plug Dot

## Overview

The **Mute-Plug Dot** is a filled circle with a soft edge—meaning *courtesy mute seated; gossip tech sleeping*. Not censorship as lifestyle; night manners for arrays and reeds.
