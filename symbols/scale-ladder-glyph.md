# Scale Ladder Glyph

## Name

Scale Ladder Glyph

## Overview

The **Scale Ladder Glyph** is a five-rung vertical mark (world / realm / region / place / phenomenon) stamped or inked on primer cards and House junior sheets.

## Meaning

Order of containment and hosting. Rungs 1–4 *contain*; rung 5 is *hosted*. Swapping the verbs is the classic wrong nest.

## Usage

Morning clerk drills; gallery wall keys beside wrong-map exhibits; Softfruit chapbook margins.

## Lore Connection

House juniors prefer the ladder; Softfruit prefers Nest Marks. Both customs accept either if the student can explain the stack aloud.

## Notes

The glyph is pedagogy, not a claim that only five scales exist in poetry.
