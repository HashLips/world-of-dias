# VEL Mark Board

## Overview

The **VEL Mark Board** is the posted conversion table at markets and gates where traders settle disputes by converting to **VEL marks** at the day's published rate—no insult, no delay, trade moves on.

## Meaning

The board represents **agreed reality for a day**: value made visible so strangers can cooperate. In story terms it is Dias's everyday sorcery—layered economies held together by a number everyone can point to.

## Usage

Consulted before arguments escalate; touching the board edge while reading is common but not required. Tampering with a board is a serious civic offense in Nauw trade law.
