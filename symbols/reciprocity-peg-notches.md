# Reciprocity-Peg Notches

## Name

Reciprocity-Peg Notches

## Overview

**Reciprocity-Peg Notches** are paired tick pairs—one “given,” one “taken”—meaning reciprocity must face both ways.

## Meaning

Pegs that only notch taken get snapped. Kindness is not a House career; theft-by-tally is still theft. Aligns road ethics with Wabet harvest spirit.

## Usage

- Burned into Fruit-Road Reciprocity Pegs.
- Orchard crew boards and Softfruit comedy courts.
- Wired Bloom teaching: mend marks before pick.
- Handbills that show only “taken” get this symbol crossed out.

## Lore Connection

Fruit-road reciprocity-peg rule. Wabet and Reciprocity / Fruit-Road Travel primers.

Tally manners glyph. Open Hand cousins welcome; Forced-Final “we’re owed” speeches are not.
