# Wabet-Restraint Line

## Name

Wabet-Restraint Line

## Overview

The **Wabet-Restraint Line** is a single horizontal pause stroke—meaning *hold the hand*; silence can be speech, pick can wait.

## Meaning

Restraint is memory practice. Forced-Final harvest chatter fails. Kin to Wired-Bloom Star (mend first) and Open-Hand Palm (give open).

## Usage

- Orchard path boards and restraint-memory cards.
- Harvest kits when blooms travel fruit-road.
- Softfruit chapbooks teaching pause before pick.
- Strike on “take now” visitor tours.

## Lore Connection

Wabet Restraint Memory and Silence-as-Speech. Reciprocity harvest rule and Wired-Bloom Star.

## Notes

Wabet manners glyph. Not a Mute-Plug Dot (civic night tech).
