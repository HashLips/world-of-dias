# House-Study Path Mark

## Name

House-Study Path Mark

## Overview

The **House-Study Path Mark** is a forked path with one House-leaning arm—meaning *study toward House craft* without pretending Softfruit or Operator paths are the same fork.

## Meaning

Learning tracks are real. Forced-Final “one path only” pride fails. Softfruit keeps a ladle fork; Operators keep a wedge fork; this mark names the House arm honestly.

## Usage

- Clerk and House Study Paths chapbook covers.
- Academy boards and tea-house cooling wait lists carefully.
- Teaching cards: crest, wedge, ladle as path cousins.
- Comedy slash on sold “instant House mastery” kits.

## Lore Connection

Clerk and House Study Paths culture. Resonant Houses institutional texture without solving sealed mysteries.

## Notes

Study path glyph. Not a clearance stamp.
