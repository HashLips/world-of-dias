# Kiln-Laughter Token Mark

## Name

Kiln-Laughter Token Mark

## Overview

The **Kiln-Laughter Token Mark** is a small round token face with a crack-smile tick—meaning *firing earned with laughter manners*, not Forced-Final silence.

## Meaning

Joy is process hygiene. Tokens without shared breath fail the yard. Softfruit loves this mark; Houses sometimes misread it as unserious.

## Usage

- Kiln Laughter Firing Token faces and yard boards.
- Halden teaching cards for new firers.
- Festival kits beside Melting-Smile Drip carefully.
- Comedy slash on mute-pride kiln cults.
