# Operator Scrap Listening Nook

## Name

Operator Scrap Listening Nook

## Overview

The **Operator Scrap Listening Nook** is a Calibration Row alcove where anonymous load scrap is sorted by ear before it is filed as noise—Operator-adjacent craft without an Operator badge.

## Description

Narrow, conduit-warm, one stool, a shelf for tokens. Couriers like Kesh leave chips; Row hands listen for hum that means “read tonight” versus “burn.” After Caliburn escape talk, late mutters sometimes answer from the pipes one beat late. Official language still says weather.

## Lore

Load-noise filing manners made into a place. Bridge between Drop Wall routes and Veld alcove nights. Not a core terminal—mythic listening, not an app store.

## Stories or Depictions

*What Operators Call Noise*; *Not Tonight Clearance* contrast (here you listen; there you wait).

## Notes

Open question: who audits the nook when Houses want the scrap stamped nonactionable before anyone hears it.
