# Emberfile Workshops

## Name

Emberfile Workshops

## Overview

Emberfile Workshops are an F840 craft district where recovery tools are filed, remade, and logged after catastrophe weather. F432 knows them mostly as imported technique names and stubborn repair ethics.

## Description

Ash-warm rooms, labeled drawers, workers who speak in continuity checklists. The district’s pride is not beauty; it is that a broken thing can re-enter use without pretending it was never broken.

## Lore

Useful later for sagas about aftermath specialists visiting F432—or F432 exiles learning repair without Hearthvale’s second-beginning language.
