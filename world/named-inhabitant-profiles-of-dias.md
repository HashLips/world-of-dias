# Named Inhabitant Profiles of Dias

## Overview

**Named Inhabitant Profiles of Dias** is the Volume IV.9 definition sheet: consistent reference cards for important named figures—identity, origin, role, relationships—usable as encyclopedia entries.

## Core Premise

### Profile fields (required for saga-facing / civic seats)

| Field | Meaning |
| --- | --- |
| **Identity** | Kind + how they are addressed |
| **Origin** | Where they rose / what weather shaped them |
| **Role** | Office or practiced job |
| **Relationships** | Who they lean on, oppose, or orbit |
| **Soft limit** | What this entry must not solve |

Historical memory names stay on [Historical Figures of Dias](historical-figures-of-dias.md)—do not collapse living seats into ancient toasts.

## Audit checklist

When enriching a named person:

1. Fill empty `culture:` if a pack applies (Concord, Watch, Compact, etc.).  
2. Keep kind record consistent with Peoples Physical Traits.  
3. Prefer additive relationships over overwriting origin.  
4. Frame conflicts as contested belief, not silent rewrite.
