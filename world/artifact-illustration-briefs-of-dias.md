# Artifact Illustration Briefs of Dias

## Overview

**Artifact Illustration Briefs of Dias** is the Volume V.10 sheet: consistent shapes, materials, dimensions, and details for important artifacts and machines—so they can be drawn from canon without guessing.

## Core Premise

### Plain rule

Prose must specify **shape / material / scale / one tell**. Flagship objects get this pack; everyday cousins inherit weather from Visual Culture Briefs.

Peoples/dress/architecture: [Visual Culture Briefs of Dias](visual-culture-briefs-of-dias.md).

## Drawing rules

| Do | Don’t |
| --- | --- |
| Show wear, salt, ash, fruit stain | Sterile sci-fi chrome default |
| One mark max unless scene is about marks | Cover object in unexplained glyphs |
| Match regional dress/architecture behind | Earth phone / subway aesthetics |
| Leave soft-limit objects visually humble | Make No-Ferry look like a ticket kiosk |
