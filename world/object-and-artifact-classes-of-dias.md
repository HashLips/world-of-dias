# Object and Artifact Classes of Dias

## Overview

**Object and Artifact Classes of Dias** is the Volume V.1 taxonomy: common objects, tools, technologies, resonant devices, and rare artifacts—so a kitchen tool is never filed as a Prime Relic by accident.

## Core Premise

### Plain rule

Classify by **role in a scene**, not loot tier. History weight can sit on a ladle; power alone does not make a relic.

### Taxonomy (book-usable)

| Class | What it is | Scene job | Examples |
| --- | --- | --- | --- |
| **Mundane tool** | Dead-enough matter; slight echo at most | Cook, mend, haul | Ordinary knives, carts, kiln tongs |
| **Everyday resonant** | Ordinary wonder; slight alive behavior | Market, table, road manners | Softfruit Ladle; loft hail chalk; flower pots; share-knife |
| **Civic / joy object** | Belonging, festival, assent | Welcome or revoke | Assent ribbon spool; ring-fair token; Banner Soft-Brush |
| **Personal resonant tech** | Pocket instruments with mythic failure | Clearance, short message, jot | Ring-pass wafer; tone-mark reed; pocket load slate |
| **Document / evidence** | Paper, slate, song calendar, seal | Prove, mislead, move carts | Span Toll Book; House sealed beta note; Mir Weekly Leaf |
| **Transport gear** | Moves bodies / cargo | Journey logistics | Skiffs, crawlers, load straps, ferry windows (local) |
| **Craft / maker tool** | Workshop process | Revision, undo, heat | Clean-undo kits; kiln slates; Open Hand scaffold habits |
| **Resonant device (restricted)** | Needs clearance / Keep / House | Seal, filter, classify | Harmonic filters; water instruments; core instruments |
| **Danger / taboo invention** | Wounds rooms, wells, memory, undo | Plot pressure | Thin-Room Ear; Forced-Final Clamp; Well-Beacon Shard |
| **Resonant shard** | Matter preserving frequency/echo | Gift, omen, argument | Roadglow Shard; Basin Rail Shard |
| **Major relic / Prime class** | Prime Age / realm-weight attributions | Saga hinge—disputed origins OK | Prime Relics; Prime Bridge; Golden Tear cousins |
| **Mutable / unfinished object** | Refuses final certainty | Map, coastline, draft | Half-Made Atlas; Open Hand unfinished tools |

Umbrella class page: [Resonant Artifacts](../artifacts/resonant-artifacts.md). Function index: [Artifacts of Dias](artifacts-of-dias.md). Lived tech: [Technology of Dias](technology-of-dias.md).

## Rarity language (use carefully)

| Word | Means in Dias | Does not mean |
| --- | --- | --- |
| **Common** | Markets stock it | Powerless |
| **Local** | One region’s manners | Worthless elsewhere |
| **Restricted** | Clearance required | Automatically evil |
| **Rare** | Few exist or few admit | Automatic plot win |
| **Taboo** | Social freeze if used openly | Impossible to build |
| **Relic** | Historical / disputed weight | Wish engine |

## Sorting test (kitchen vs relic)

Ask in order:

1. Does it mainly feed, mend, or meter ordinary life? → everyday / mundane  
2. Does it mainly prove or move information? → document  
3. Does it need Operator/House/Keep assent to touch? → restricted  
4. Does misuse thin rooms, wells, or undo? → danger / taboo  
5. Do Houses/sagas argue its Fracture/Prime origin? → major relic  

Never skip to (5) because an object glows.
