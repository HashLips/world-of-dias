# Time Causality and Change of Dias

## Overview

**Time Causality and Change of Dias** states what is established about how time, cause-and-effect, and change behave—and labels what remains unknown so F432 habits are not globalized by accident.

## Core Premise

### Plain definitions

| Term | Definition |
| --- | --- |
| **Civic time (F432)** | Ordinary lived clocks, seasons, markets, and era markers people use in the home band |
| **Band time-feel** | How a frequency layer alters recurrence, revision, recovery, or interval truth |
| **Causality** | What reliably follows from what—band-dependent where established |
| **Change** | How forms, scars, and stories are allowed to alter |

### Established (do not invent against these)

| Domain | Established rule | Entry anchors |
| --- | --- | --- |
| F432 chronology | Soft era markers; no single universal calendar | Known Eras and Markers; F432 Civic Time |
| Fracture ordering | Prime Age → Fracture → Present Age | The Fracture; The Present Age |
| F120 | Near-return with drift—not exact time loops / rewind ferries | F120 near-return drift rule |
| F960 | Forms revise by default; persistence = repeated holds | F960 iterative manifestation rule |
| F840 | Recovery is incremental continuity, not miracle reset | F840 recovery continuity rule |
| F610 | Truth can be interval-bound (windows), not permanent open archive | F610 reveal window rule |
| Echo / memory | Remainder persists; scrape ≠ erase; seals hide access more than annihilate | Memory is band-shaped; Echoes can be sealed not destroyed |
| Soft limits | No wish-engine; no ferry from “remembering harder” | Resonance does not grant wishes |

### Unknown / not established globally

| Gap | Label |
| --- | --- |
| Whether all bands share one absolute clock | **Unknown** — do not assume |
| Exact year-counts since Fracture | **Unknown / culturally imprecise** |
| Full causality map for F500 null approach beyond thinning/softening | **Partial observation** |
| Whether F200 “clarifies” time or only attention/memory noise | **Partial / disputed** |
| Prime Age duration | **Myth-touched unknown** |

### Teaching warning

Do not copy F432 market hours onto every realm. Band primers and domain-effect entries override home-band assumptions where they conflict.

## Global Lore

Known Eras and Markers is the soft chronology sheet. Band rules above are the hard edges. Mysteries of Dias holds crown gaps that intersect time-talk (including Zero).
