# Plant Use Classes of Dias

## Overview

**Plant Use Classes of Dias** sorts named plants by how inhabitants use or refuse them: edible, medicinal, dangerous, commercial, culturally significant—with warnings and taboos plain.

## Core Premise

### Plain classes

| Class | Meaning | Examples |
| --- | --- | --- |
| **Edible** | Kitchen, forage, staple (ethics still apply) | Market Banana; Basin Mist-Herb; Hearthvale Stew-Onion |
| **Medicinal** | Heal, soothe, rope-softener, smoke pest | Hollowmere Net-Moss; Cinder Nook Tar-Herb |
| **Dangerous / hazard** | Harm, overload, omen burn | Bleed-Sky Nightbloom; Blue Litter pressure; some else-green |
| **Commercial** | Trade, dye, ink, float craft, fodder | Ringfair Dye-Marigold; Averra Inkcap; Rim-Rest Raftweed |
| **Cultural / sacred-soft** | Rank, vow, ritual, sharing rules | Market Banana (fruit apex); Rope Tree etiquette; Quiet Well approach plants |
| **Observed only** | Named but not harvested casually | Sketchy Gallery Dustfern; some Averra studio growth |

### Warnings (plain)

1. **Fruit rank is manners**—supreme banana talk is culture, not permission to steal Wabet orchards.  
2. **Sacred-soft harvest** needs vow or assent (Rope Tree, Quiet Well approaches).  
3. **Hazard flora** can be beautiful; beauty is not a cook tip.  
4. **Else-green** (other-frequency growth) is not F432 pantry stock.  
5. **Yard and Freeband greens** (nettle, bittercress) feed second beginnings—do not romanticize hunger.

### Cook / heal / trade / avoid (quick grid)

| Need | Start with |
| --- | --- |
| Cook | Market Banana; Basin Mist-Herb; stew onion; Soft-Bear Berry (share etiquette) |
| Heal / soothe | Net-Moss; tar-herb pest smoke; camp nettle (careful) |
| Trade | Dye-marigold; inkcap; raftweed; peel-vine fodder |
| Avoid / refuse | Bleed-Sky Nightbloom; Blue Litter bottling; map-wrong oasis stripping |
