# Quiet Places of Dias

## Overview

**Quiet Places of Dias** indexes intentional quiet—cloister beads, between-repetitions, Quiet Well shade—against noise that pretends to be honesty.

## Core Premise

Quiet can be shelter craft. Silence as punishment is a different tool.
