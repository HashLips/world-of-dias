# Speech Etiquette and Naming of Dias

## Overview

**Speech Etiquette and Naming of Dias** is the Volume IV.4 definition sheet: how to name a character correctly and stage a polite vs rude exchange from canon—without a full conlang.

## Core Premise

### Plain rule

A writer needs three tools: **name pattern**, **address form**, and **register** (soft / civic / hard). Texture lives in regional speech files; this sheet is the staging test.

### Exit test (polite vs rude)

| Place | Polite open | Rude open | Clean repair |
| --- | --- | --- | --- |
| **Nauw market** | Softfruit ladle + fruit-rank share; “neighbor” or given name | Banana-boast; “say it like a person” to Choirglass | Re-share rank; apologize without joke |
| **Wabet trail** | Soft steps; silence-as-answer accepted | Shout wells; demand maps | Soft apology walk; leave fruit as make-good |
| **Hollowmere loft** | Answer First Line; learn one stanza | Miss check-in; pretty excuses | Make-good stanza before exit |
| **Claimscar kettle** | Bowl + name; wire or news | Concord boots as rank; joke during mourning hang | Honest debt mark; second bowl if earned |
| **Veloria desk** | Steward/soft honorific; form explained once | File person as number; jump rings with swagger | Correct the stamp; second-ring tea if invited |
| **Calareth porch** | Wait for ribbon; role-address Watch | Move stone; bay-name without assent | Belonging repair or bed refusal accepted |
| **Shared Table (any)** | Name before frequency/kind; front-plane for Lineborn | Count Palewind motes; shout Veyrin trait | Continuity-name ask; table apology |

## Naming quick map

| Need | Pattern feel | Avoid |
| --- | --- | --- |
| Nauw civic | Short given + craft/place (*Lira Pot*) | Overlong titles in market queues |
| Wabet soft | Soft vowel trails (*Yara Moss*) | Loud nicknames near Silence Law |
| Sorel exile | Hard consonants (*Garen Scar*) | Concord honorifics as self-promotion |
| Rim crew | Two-beat usable in shout (*Marek Solon*) | Pretty names that break under storm call |
| Choirglass | Tone-mark + spoken handle | Demanding the tone-mark alone as “real name” |
| Palewind | Continuity-name for the person | Naming partitions as separate citizens |
| Draftkin visit | Revisable name; ask if still current | Freezing a draft name as mockery |
