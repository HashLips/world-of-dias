# Field Guide Pattern of Dias

## Overview

**Field Guide Pattern of Dias** is the repeatable book pattern for plant and creature entries: appearance, habitat, scale, distinguishing traits, and use or caution—so Volume III can produce illustrated field-guide pages without reinventing structure each time.

## Core Premise

### Plain pattern (every guide entry)

| Block | Answers |
| --- | --- |
| **Name** | Local and archive name |
| **Life kind / kind tag** | Ordinary animal, extraordinary creature, people (rare in guides), ambiguous, or flora kind |
| **Look** | Size, color, silhouette, smell if useful |
| **Where** | Habitat + region nest (not “everywhere magic”) |
| **Behavior / habit** | How it moves, grows, or waits |
| **Tell** | One trait that prevents mix-up with a cousin |
| **Use / caution** | Food, craft, medicine, taboo, hazard—or “observed only” |
| **Status** | Canonical field fact vs rumor/legend |

### Art / plate brief (when illustrated)

Artwork entries should state: **subject**, **scale cue** (hand, cart, tree), **habitat backdrop**, **one distinguishing feature** in the pose. Text remains identifiable even without the plate.

### Demonstrators (pattern already working)

| Entry | Why it demonstrates |
| --- | --- |
| Band-Answer Moss | Look + teaching use + soft-limit caution |
| Canopy Soft-Bears | Size, Softfall habit, wonder class, fruit etiquette |
| Ringroad Dogs | Civic look, route behavior, collar life |
| Market Banana | Cultural apex + import habitat honesty |
| Quietwell Serpents / Redmile Striders | Hazard tells + avoidance custom |

## Global Lore

Flora of Dias and Animals / Creatures indexes feed the guide. Ecosystems and Habitats of Dias place the “where.” Plant Use Classes of Dias tags kitchen / medicine / danger / trade / culture.

## Notes

Not every species needs art yet. Pattern first; plates follow. Soft limits: no Zero bestiary; no band-ferry seeds.
