# Place-Type Vocabulary of Dias

## Overview

**Place-Type Vocabulary of Dias** names the ordinary scale words inhabitants and clerks already use for places—*realm, region, city, town, district, landmark, island, crossing, building*—and how those words sit under the nesting hierarchy without becoming a second metaphysics.

## Core Premise

Frequency realms answer *which vibrational layer*. Place-types answer *what kind of geography inside a layer*. Local phenomena answer *what pattern of event can visit*. Mixing the three vocabularies is the root of wrong nests.

### Vocabulary table

| Word | Typical use | Nest note |
| --- | --- | --- |
| **realm** | Frequency layer (F432…) | Parent is Dias |
| **region / territory** | Broad land or sea body | Inside a realm |
| **city / town** | Settlement with civic habits | Inside regions |
| **district** | Part of a city | Still a place rung |
| **landmark** | Named geography without always being a government | Place rung |
| **island / crossing** | Special geography / threshold | Place rung |
| **building / shop / pub / gallery** | Rooms and thresholds | Finest common place rungs |
| *(not a place-type)* **phenomenon** | Recurring event | Hosted by places |

## Global Lore

Archive files use these words in frontmatter so the dashboard Map and graph stay honest. Softfruit rarely says “place_type,” but Stack Teaching Customs teach the same distinctions with bowls and Nest Marks. Houses prefer Scale Ladder Glyphs and primer cards.

Poetry may call a city “a whole world.” Ledgers may not.

## Notes

Worked chains live in place entries themselves via `parent_region` and nesting notes. Binding rules: Dias nesting hierarchy; Local phenomenon scope rule; Frequency realm is not a country.
