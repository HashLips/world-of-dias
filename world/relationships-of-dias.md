# Relationships of Dias

## Overview

**Relationships of Dias** is the web—place ↔ people ↔ faction ↔ creature ↔ artifact ↔ rule—so pulling one thread visibly moves three others, and the world still feels wonderful.

## Core Premise

Prioritize **F432 hubs** first. Cross-frequency links stay thin threads, not subways. Record **affections** as carefully as enmities. Full indexes live elsewhere; this page is the relationship pass.

Stage status for authors: [`Stage Readiness of Dias`](stage-readiness-of-dias.md) · agent note [`agent/stage-readiness.md`](../agent/stage-readiness.md).

## How to read a thread

| Pull… | Expect movement in… |
| --- | --- |
| A place | Jobs, table manners, local creature pressure, one org face |
| A faction | Soft-power venue, a seal/secret type, a rival affection |
| A creature | Folklore family, travel custom, sometimes a mystery card |
| An artifact | Evidence genre or joy/danger function, a holder’s motive |
| A rule | Speech soft words, learning path, death/legacy practice |

## Pull-one-thread examples
