# F432 Journey Routes of Dias

## Overview

**F432 Journey Routes of Dias** is the journey-planner sheet: named roads, spans, local ferries, trade corridors, and physical constraints between major home-band destinations—without pretending any of them are inter-frequency tickets.

## Core Premise

### Plain definitions

| Term | Meaning |
| --- | --- |
| **Road / fruit road** | Packed or marked land corridor for freight and feet |
| **Toll / span** | Payment and manners checkpoint on a corridor |
| **Local ferry** | Water crossing inside F432 (isle, rim, river) |
| **Exile bridge / gate** | Threshold with moral and civic weight (e.g. Long Gate) |
| **Constraint** | Weather, manners, cost, danger class, or soft limit that slows or blocks |

**Local ferry ≠ band ferry.** Soft Limits of Dias still hold.

### Sample journey (believable day-chain)

Wabet Softfall orchard → Eastbound Fruit Road → Span Toll → Velorian Basin / DEB Gate → ring markets. Alternate south: Basin → Long Gate → Hearthvale → Driftfall Salvage Shore. West silence: Lumira via Saltwhisper (Keep assent). None of these leave F432.

### Soft limits (travel)

- No scheduled service to F200 / F500 / Zero  
- Returning Span / Glassfold / Hearthline metaphors are omenized, not subwayed  
- Sky Drifters are not vehicles
