# Frequency and Memory of Dias

## Overview

**Frequency and Memory of Dias** defines how recollection and world-remainder behave under different frequency bands.

## Core Premise

### Plain definition

**Band-shaped memory** means: which frequency you are in (or near) changes how events stick, return, thin, open briefly, scar, or revise—in persons and in places. Memory is not only a private talent inside a skull.

### What this is not

- Not total surveillance
- Not a guarantee of perfect transcripts
- Not proof that every echo is readable on demand
- Not a ferry ticket (“remember harder and arrive in F200”)

Softfruit starts with Kneaded Dough Memory and Table-Warmth Recall before anyone says “cognition.” Echoes (world remainder) and personal memory braid; they are not identical.

### Band memory habits (working expectations)

| Band | What memory does | Danger if misread |
| --- | --- | --- |
| F432 | Civic/kitchen remainder; ledgers and meals keep sticky use | Treating scrape as erase-lie |
| F120 | Phrase/scene rhyme with drift (near-return) | Calling rhyme a closed time loop |
| F500 | Continuity thinning with proximity | Sport tourism into erasure weather |
| F610 | Window-bound witness; phase-stamped interval recall | Endless stare fantasy |
| F840 | Scar continuity—keeping what still needs care | Forced-Final “all healed” speeches |
| F960 | Recollection that admits revision of earlier forms | Shame for changing a held story |
| F200 | Clarity-without-flood recall under coherence | Assuming luminosity grants total recall |
| F380 | Mood-colored shared recall under hearttide climate | Private blame for climate-scale feeling |

### Echo vs personal memory

Echoes are partial remainders the world holds. Personal memory is a person’s craft of keeping and refusing. They braid; they are not identical. Resonance behavior soft limits forbid turning either into omnipotent surveillance.

## Global Lore

Memory is band-shaped is the rule spine. Nauw Civic Memory, Wabet Restraint Memory, and Echoes of the Dead are cultural faces inside F432. Cross-band phenomena named above keep the primer from staying Softfruit-only.

## Notes

Does not solve Frequency Zero as “memory’s absence.” Does not grant F610 permanent archive eyes.
