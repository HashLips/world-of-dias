# F120 Lab Drift Log Custom

## Name

F120 Lab Drift Log Custom

## Overview

**F120 Lab Drift Log Custom** is how Calibration Row logs “near-return” drift—rhyming repeats in instrument behavior—without calling it time travel or selling a loop you can ride to yesterday.

## Beliefs and Values

Drift is a **pattern family**, not a ferry. If a run echoes an earlier run, you record protocol and outcome rhyme; you do not claim the room went backward. Scraped corrections keep the error history legible so “same as Tuesday” can be checked.

## Practices and Traditions

A typical log line looks like: *Protocol: heel-hum + F120 ghost pass. Outcome rhyme: third tick softens, then recovers. Not a loop.* Hobby logs on the Row predate Orrin. When the Spectrum Frame showed F120-like signatures from inside F432, Orrin used the same custom so triumph would not turn into subway talk.

## Lore

Tied to F120’s near-return character in Dias frequency lore. The Calibration Saga uses it in Movement One teaching and Frame runs—proof without portal fantasy.
