# Wabet Restraint Memory

## Overview

**Wabet Restraint Memory** is western history as chosen calm: wrong maps as mercy, ribbons as law, orchards as reciprocity, and hollows that refuse advertisement.

## Beliefs and Values

Not every past should be published. Forgetting a well’s exactness can be care. Remembering Blue Litter caution can be survival.
