# Labor Types of F432

## Overview

**Labor Types of F432** catalogs ordinary work textures—orchard, ledger, salvage, watch, song, forge, ferry—so characters have jobs, not only destinies.

## Beliefs and Values

Work can be loveable. Work can be pressure. Dias needs both on the page. Race does not assign caste; patterns of who thrives where still exist (Kharad kilns, Choirglass tone-desks, etc.).

### Child → adult paths

Orchard-kids learn share ledges before wage talk. Rim kids learn rope-before-stone. Clerk apprentices learn soft address before stamp power. Vent kids learn kettle before paint.

### Kindness practice

Pay labor tenders (rest, news, wire) when VEL is short but work is real.

### Hard edge

Pretending Watch/Keep work is unpaid hobby; stealing song-route memory as private IP without custodianship duty.
