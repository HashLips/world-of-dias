# Speed Truth Tradeoffs

## Overview

**Speed Truth Tradeoffs** is the living rule that the fastest word is rarely the truest—and the truest word often arrives after the kettle has already boiled over.

## Beliefs and Values

Window talk is true briefly. Again-but news recurs wrong. Filing can stabilize panic and also kill witness. Dias needs all three habits—and arguments about which to trust tonight.

## Practices and Traditions

### Tradeoff kit

| Need | Prefer | Cost |
| --- | --- | --- |
| Save a raft tonight | Loft hail / gangplank | Gossip injury if wrong |
| Prevent market panic | House label (slow) | Sealed silence feels like abandonment |
| Fair yard fight | Salt Ledger overlap | Slow; crews impatient |
| Keep water alive | Wrong maps / path-only | Travelers call it lying |
| Catch a reveal | Veil phase stamp | Truth expires; false certainty sin |
| Fair week mood | Mir leaf / moth talk | Comic dread becomes real dread |

### Sample plot engines

- A true loft hail arrives after a false Mir headline.  
- A House seal is correct and late; a street warning is early and half-wrong.  
- Window talk sold as permanent verdict.

## Kindness practice

Say your certainty grade when you pass news (known / disputed / rumor).

## Hard edge

Speed as weapon—flooding channels to drown a Mutual Table warning.
