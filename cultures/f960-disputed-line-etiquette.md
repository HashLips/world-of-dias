# F960 Disputed Line Etiquette

## Name

F960 Disputed Line Etiquette

## Overview

**F960 Disputed Line Etiquette** is how to speak “unfinished / becoming” without forcing catalog finality—and without turning a disputed margin into ferry geography.

## Beliefs and Values

Some Supplemental Harmonic Ledger Leaf copies add F960; some strike it. Name becoming as disputed. Never baptize it as settled passage. Selling the argument is allowed; selling the verdict as ticket is not.

## Practices and Traditions

Orrin kept the F960 stutter unnamed (or blank) on the first residual graph on purpose. Bram Inkspan sells variant copies from separate drawers—argument, not verdict. School chalk may include a fifth ghost column marked *disputed*. Issa’s packet footnotes the etiquette so readers do not invent a sixth dock.

## Lore

Tied to Half-Made Atlas–style mutable cartography rumors. The Calibration Saga keeps Frequency Zero and Frederick’s crossing untouched; F960 etiquette is part of that restraint.
