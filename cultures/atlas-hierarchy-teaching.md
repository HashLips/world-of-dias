# Atlas Hierarchy Teaching

## Name

Atlas Hierarchy Teaching

## Overview

**Atlas Hierarchy Teaching** is the Softfruit and clerk custom for teaching geographical nest chains—realm, region, settlement, landmark—before anyone draws a journey or seizes a wrong map.

## Beliefs and Values

Feet need honest containers. A landmark is not a frequency. A city is not a realm. Skip-level parents make ferry fantasies.

## Practices and Traditions

Teachers set the Atlas Hierarchy Ladder Card beside four bowls (Stack Teaching) and ask for a full chain out loud.

| Prompt | Acceptable answer shape |
| --- | --- |
| Where is Softfruit Table Hall? | Dias → F432 → Nauw → Velorian Basin → Veloria City → Softfruit Table Hall |
| Where is Quiet Well? | Dias → F432 → Wabet → Lumira Sands → Quiet Well |
| Where is Claimscar Yard? | Dias → F432 → Sorel → Driftfall → Claimscar Yard |
| Where is Returning Span? | Dias → F120 → The Returning Span (not a Nauw district) |

Wrong Nest Corrections still catch “F500 is east of Driftfall.” Atlas Hierarchy Teaching catches “Veloria’s parent is F432” (skipped Basin/Nauw).

## Lore

Stack Teaching asks scale of meaning. Atlas Hierarchy Teaching asks scale of geography for journeys. Both refuse No-Ferry violations.
