# F432 Naming Patterns

## Overview

**F432 Naming Patterns** describes how people, places, crews, and quiet things get names—enough pattern for dialogue and census tags without a constructed language.

## Beliefs and Values

A name should be **usable in a shout and survivable in a ledger**. Pretty names that break under storm check-in or claim paint are bad names. Some names are gifts; some are warnings; some are unfinished on purpose.

## Practices and Traditions

### Personal names (humanoid-majority habits)

| Pattern | Where common | Examples / feel |
| --- | --- | --- |
| Short given + craft/place | Nauw cities | Lira Pot, Pell Rim, Havren Pike |
| Soft vowel trail names | Wabet canopy / reach | Soen Tide, Yara Moss, Maes Thorn |
| Hard consonant exile names | Sorel | Garen Scar, Carrow Vale, Vexra Coil |
| Two-beat rim names | Outer Rim | Marek Solon, Jessa Quill, Pell Rim |
| Ribbon / assent names | Calareth | Coris Vale; visitors often keep home names + temporary bay-name |

Nicknames stick faster than formal names on fruit roads and gangplanks. Refusing a nickname can be dignity—or snobbery.

### Non-humanoid naming

- **Choirglass:** often a tone-mark plus a spoken “handle” for F432 markets (*Zephan Quell*). The handle is courtesy, not the whole self.
- **Palewind:** continuity-name for the swarm-person; partitions do not get citizen names unless a split rite says so.
- **Axiomorph:** pattern-names or facet-counts used among themselves; trade names chosen for human mouths.
- **Lineborn:** names that flip well in profile—short, high-contrast syllables.
- **Kharad:** often mineral, kiln, or load metaphors (*Hanna Kiln*).
- **Veyrin:** given name + quiet trait-epithet used only by intimates (“salt-memory Mira”—never as a carnival shout).
- **Draftkin (visiting):** names that tolerate revision; asking “is that still your name this season?” is polite in F960, odd in Veloria.

### Place names

- **Descriptive compound:** Softfruit Table Hall, Claimscar Yard, Ringwash Baths, Eastbound Fruit Road.
- **Law-in-the-name:** Quiet Well, Rope Tree, Long Gate, Good Trade.
- **Warning names:** Redmile (folk), Saltwhisper, Stillhollow.
- **Do not “correct” Calareth or Lumira place-names toward accuracy**—wrong maps can be mercy.

### Crew, House, and kettle names

- Driftfall crews name for scar, vent, or joke (*Hungry Dogs* mood).
- Resonant Houses use numbered or coded identities in public channels; street speech shortens them.
- Raft-rings name for leeward habit or an old captain’s tea.

### Renaming

Exile often brings a second name. Secondfire slate culture treats remaking names as craft, not erasure—unless the person asks for erasure. Stealing someone’s exile-name for comedy is an insult that can start fights.

## Lore

Census houses prefer stable tags; poets prefer true ones. F432 lives in the argument between them.

### Naming scene beats

| Situation | Correct | Rude |
| --- | --- | --- |
| New Softfruit guest | Ask preferred table-name; use regional pattern | Rename them for a joke |
| Palewind ledger | Continuity-name once | List partitions as separate citizens |
| Exile arrival | Accept second name; don’t steal it for comedy | Demand their “real” Concord name |
| Draftkin season | “Still your name this draft?” | Freeze a draft name as mockery |
| Loft shout | Two-beat name that survives wind | Pretty name that breaks under First Line |
