# Resonance Feat Sorting Customs

## Name

Resonance Feat Sorting Customs

## Overview

**Resonance Feat Sorting Customs** are Softfruit and junior House practices for sorting a proposed resonant feat into **succeed**, **fail**, or **forbidden/taboo** before anyone builds, sells, or brags.

## Beliefs and Values

Desire is allowed. Guessing physics from desire is not. A feat that ignores cost is already failing manners. Frequency Zero and ferries stay unfinished even when a student begs for a clever exception.

## Practices and Traditions

Hosts set three bowls or three chapbook columns: Succeed / Fail / Forbidden.

| Sort question | If yes, lean… |
| --- | --- |
| Does it use ordinary remainder + known craft? | Succeed |
| Does it claim total knowledge, free wish, or commute ferry? | Forbidden |
| Does it ignore cost or consent? | Fail or Forbidden |
| Is the band habit wrong for the tool (draft timber as bridge oak)? | Fail |
| Is it rare/exceptional crossing treated as omen, not schedule? | Succeed only as exception story—not infrastructure |

Softfruit Certainty Manners apply: do not stamp Theory on a wish. Houses may add Claim Grade stamps after the sort. Restricted and Taboo Tech supplies the freeze list for devices.

## Lore

Stack Teaching asks where something sits. Five-Domain Effect Teaching asks what a band changes. Feat Sorting asks whether a proposed use of resonance is allowed to work as claimed. Juniors who pass all three can host without inventing subways.
