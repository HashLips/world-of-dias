# Ring-Fair Lights Customs

## Overview

**Ring-Fair Lights Customs** are Veloria’s civic spectacle habits—shared tables, fair tokens, Banner Moth wonder—without letting stamp theater eat the joy.

## Beliefs and Values

Spectacle should feed neighbors. A fair that only advertises Houses has failed the rings.

## Practices and Traditions

| Beat | Custom |
| --- | --- |
| **Lights up** | Outer rings parade first; inner rings host quieter shared tables |
| **Token** | Ring-fair tokens buy food and games—not gate privilege |
| **Table** | Compact kinds sit mixed; Softfruit ladles keep noticing manners |
| **Clerk pause** | Forms wait; explaining a stamp mid-dance is rude |
| **Close** | Leave light without filing gossip as census |

## Lore

Pairs with Ring Protocol expectations and Civic Time’s Ring-Fair Lights season. Constructed wonders (Festival Sky-Whales, Banner Moths) are allowed awe— Forced-Final cheer is not.

## Kindness practice

Share a table with someone who cannot buy the pretty token.

## Hard edge

Stamp theater that ruins joy; using fair crowds to exile by paperwork.
