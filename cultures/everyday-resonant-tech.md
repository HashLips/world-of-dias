# Everyday Resonant Tech

## Overview

**Everyday Resonant Tech** is the wonder in ordinary devices—tools that keep cities and roads alive without requiring Operator clearance.

## Beliefs and Values

If only the core is “tech,” the world feels fake. Dias prefers pots, knives, chalk, ladles, winches, and tokens that still behave a little more alive than dead matter.

### Transport-adjacent everyday

Fruit-road cart shades, toll chalk tallies, raft-ring rope meters, desert soft-step sand trays (training tech, not weapons).

### Wonder rule

Everyday tech may **almost remember**—a ledger that feels heavier after bad testimony, a pot code that reseeds when collectors smash it—without becoming a dungeon artifact every scene.

## Kindness practice

Maintain public pots and ladles; broken civic tech is a belonging wound.

## Hard edge

Criminalizing pot codes that feed favors; selling “everyday” gadgets that are secretly restricted listeners.
