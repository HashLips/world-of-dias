# Open Hand Maker Tech

## Overview

**Open Hand Maker Tech** is unfinished-on-purpose tooling: scaffolds, revision bands, clean-undo methods, and atlases that refuse to lie about coastline certainty.

## Beliefs and Values

True without final. Tools should teach the next hand. Sealing a harmful change under “done” is craft failure. Attribution matters; commons stewardship outranks ownership theater.

## Practices and Traditions

### Tool habits

| Habit | What you see |
| --- | --- |

| **Clean undo training** | Reverse harm without collapsing the whole |
| **Scaffold frames** | Buildings and tools that can iterate |
| **Half-Made atlases / cousins** | Maps that admit negotiation |
| **Openhand craft-hemp cordage** | Rope that remembers maker ethics on F432 Way |

### F432 presence

Open Hand Way workshops transplant etiquette: relocate wasps’ concept-nests, leave seams visible, share soup-carrot travel tech without claiming F960 citizenship.

### Kindness practice

Teach clean undo before teaching sharper cuts.

### Hard edge

Refuse forced-final tools; call out attribution theft; oppose taboo seals that erase revision rights.

## Lore

Phrase: **open hand, steady line**. Contrast with F500 null pressure and with Operator load silence—different virtues, real tensions.
