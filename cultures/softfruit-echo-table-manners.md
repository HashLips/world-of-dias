# Softfruit Echo Table Manners

## Name

Softfruit Echo Table Manners

## Overview

**Softfruit Echo Table Manners** are how Softfruit hosts teach resonance without frightening guests: the table remembers lunch, so lunch must be worth remembering.

## Beliefs and Values

- Warmth is a kind of echo. Make it on purpose.
- Do not interrogate a table like a suspect. Sit. Eat. Notice.
- Forced cheer leaves brittle aftertone; honesty leaves peel-sweet.
- A first listen is craft practice, not a verdict on a stranger’s life.

## Practices and Traditions

Hosts set the Softfruit Resonance Bowl near the ladle. Guests who arrive sharp from gate arguments are offered fruit before questions—argument-stain softens slower than hunger. Children learn to name “aftertone” as the feeling that lunch happened, not as a ghost story.

When a table feels sour for no visible reason, Softfruit scrapes the mood the way clerks scrape ledgers: wipe with vinegar cloth, speak one true apology, and do not pretend the sour never existed.

## Lore

These manners grew beside Softfruit ladle-before-stamp ethics. They are the kitchen face of Everything resonates. Travelers who only know House code bars sometimes laugh—until they notice the bowl warming after a real shared joke and staying cool after a performed one.
