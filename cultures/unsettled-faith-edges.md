# Unsettled Faith Edges

## Overview

**Unsettled Faith Edges** are present-but-not-dominant meaning hungers: null curiosity cells, unfinished prophecy, light-purity extremes—pressures that can frighten a town without owning it.

## Beliefs and Values

Dias stays loveable by keeping these edges minority and contested. They are real enough to plot with; not default culture.

## Practices and Traditions

### Edge types

| Edge | Hunger | Public face | Private fear |
| --- | --- | --- | --- |
| **Null-curiosity** | Touch absence; name Horizon too often | “Research,” dare games | Thin rooms; erasure |
| **Zero-forcing** | Make refusal into a tool | Philosophy salons | Hazard filing; sacred break |
| **Unfinished prophecy** | F960 revision as destiny script | Maker mysticism gone rigid | Forced-final outcomes; stolen agency |
| **Light-purity** | F200 coherence as moral ranking | Serenity snobbery | Contempt for carbon life; corona without consent |
| **Bleed stewardship cults** | Control stack weather | Containment virtue | Exploitation of bruise nights |
| **Exile destiny masks** | Compact as holy irreversibility | Survival pride | Fear institutionalized (Carrow-adjacent risks) |

### Authoring rule

Show edge faith through one cell, one preacher, one bad tool—not a continent converted overnight. Majority practices (fruit, ribbon, loft, kettle) still set the street.

### Kindness practice

Offer soft words and Shared Table before confrontation theater.

### Hard edge

Taboo tech for sport; recruiting kids into Null naming; purity rankings that deny personhood.
