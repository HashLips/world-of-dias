# Nauw Civic Memory

## Overview

**Nauw Civic Memory** is how the crowded heart remembers itself: rings rebuilt, gates that measure, bridges that argue, fruit dependence that never stops being funny or sharp.

## Beliefs and Values

Civic memory prefers markers over year-numbers. A gate touch can be history class.
