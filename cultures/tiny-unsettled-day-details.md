# Tiny Unsettled Day Details

## Overview

**Tiny Unsettled Day Details** are soft pressure in ordinary days—wrong-color moths, ledger flea itch, laughlight rumor—so unease never needs a villain monologue.

## Beliefs and Values

Big dread stays rare. Small wrongness keeps Dias honest. Most details resolve as fleas, dye mistakes, or gossip—and a few don’t.

## Practices and Traditions

### Detail kit (drop into any day)

| Detail | Ordinary read | Unsettled read |
| --- | --- | --- |
| Wrong-color moth on a banner sill | Dye dust; tired eyes | Bleed-season cousin; Null dare leftover |
| Ledger flea itch | Pest; sweep the eaves | Filing weather; stamp-heavy omen |
| Laughlight rumor | Someone happy two streets over | Light that laughs without a mouth (hearsay) |
| Softfruit ladle that sticks | Sticky fruit | Truce that doesn’t want to end |
| Pot that won’t hold yesterday’s code | Rain; kids | Code reseeding after a raid |
| Choir-frog hush lasting one beat too long | Storm coming | Stranger’s wrong step |
| Gate touch that feels warm | Sun on stone | Threshold remembering |
| Raft rope humming | Wind | Hail you haven’t answered yet |
| Kiln slate squeak | Clay | Name refusing to stay |
| Again-but cart at the toll | Same vendor, new joke | F120 metaphor made traffic |

### Authoring rule

One tiny detail per ordinary scene max unless Bleed-Sky is already declared. Prefer itch over apocalypse.

## Kindness practice

Teach children which details mean “shut the window” vs “brush the moth gently.”

## Hard edge

Turning every flea into Null recruitment.
