# The Town That Changes Flags

## Summary

Border stories say a strip town changes flags every week and never changes breakfast. Armies that tried to starve the table found the porridge waiting with a different cloth and the same salt.

## Myth Text

Some tell it as satire. Residents file it like minutes. Mir Weekly’s name is either homage or coincidence depending who drinks the tea.

## Notes

Municipal custom and myth braid on purpose.
