# Calibration Saga — Reading Path

Third long narrative journey of Dias. Follows **Orrin Veld** from Calibration Row craft through spectrum proof, the mischievous Echoform **the Caliburn**, a partial publish of frequency science—and an escape into Veloria’s ignored noise.

**Plot in plain talk (new readers):**

Orrin wants to graph frequency bands honestly from home band F432—no ferry, no subway.
Softfruit data and a Supplemental Leaf teach loud dramas (F200 / F500) and quieter background bands; Operators file civic wonder as “noise.”
He builds the Spectrum Frame; graphs agree; a residual seam (leftover reveal light) will not close.
The Caliburn appears helpful in the glass, then steers results by half a digit; Houses stamp it nonactionable.
It tempts him to *widen* (keep the residual run open longer—not dig a tunnel); he refuses.
Napkin overlay proves the nest was already in load-noise; he and Issa publish partial spectrum truth (soft limits held; Zero unanswered).
Vault fails; Caliburn escapes alcove → conduit → Drop Wall noise; Orrin keeps measuring with an incomplete Frame.
Frederick’s crossing stays elsewhere.
