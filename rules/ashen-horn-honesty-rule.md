# Ashen horn-honesty rule

## Name

Ashen horn-honesty rule

## Overview

Blow the **Rest Relay Horn** only when the stop can still take bodies. Vanity horns for pride travel get ignored—and then refused.

## Description

**Who follows:** Relay keepers, pony handlers, Outer Rim crews learning basin rest.

**Who breaks:** Merchants blowing “open” for fees when beds are dead; Forced-Final push-through captains; false hospitality advertisers.

**What happens:** Ponies and keepers ignore the tone; viability rule cited; shelter-first cousins close doors to the liar.

## Effect

- Protects rest infrastructure from marketing lies.
- Makes viability sonic and social.
- Soft limit against push-through speeches.
