# Averra damp-ink patience rule

## Name

Averra damp-ink patience rule

## Overview

Offshore ink and pigment **may smear if rushed**. Demand for Forced-Final dry flourish is bad courtesy; wait for damp air’s tempo.

## Description

**Who follows:** Averra hosts, damp studio apprentices, Offshore Pass guests, Sketchy Gallery prep crews.

**Who breaks:** Mainland visitors insisting on instant varnish; sellers of “instant masterpiece juice”; curators forcing finish against beauty-between-lines gaps.

**What happens:** Messy sleeves as comedy fine; passes questioned for courtesy; color bottles stay corked against the breaker. Offshore courtesy rule remains the parent; this clause is ink-specific.

## Effect

- Makes Averra patience checkable at the stick and bottle.
- Protects beauty craft from Forced-Final mainland tempo.
- Aligns pass, ink, and pigment manners.
