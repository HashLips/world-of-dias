# Ashen Hearthline rest viability rule

## Name

Ashen Hearthline rest viability rule

## Overview

Travel plans on the **Ashen Hearthline** are valid only with mapped viable rest intervals. Phrase: **no rest plan, no route.**

## Description

Route approvals require current heat, shelter, and relay checks at declared stops. Unsupported long pushes are unsafe misconduct—recovery terrain punishes miracle marches. Ember Keeper maintenance data sits at the center of planning; this rule is the road face of F840 recovery continuity.

## Effect

- Prevents avoidable exhaustion deaths.
- Keeps warmth corridors and relays politically important.
- Discourages swagger travel that burns recovery gains.
