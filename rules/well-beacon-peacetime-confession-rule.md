# Well-beacon peacetime confession rule

## Name

Well-beacon peacetime confession rule

## Overview

Kind wrongness that saves a boat in chase **must be confessed in peacetime** to anyone who later trusted the same song. Mercy maps still owe later honesty.

## Description

**Who follows:** Quiet Well keepers, rim fishers using shards, mutual-rescue stewards citing beacon cost.

**Who breaks:** Keepers who treat emergency lies as permanent policy; sellers of “always-true” shards; Houses that punish confession more than the original chase.

**What happens:** Peacetime dry-runs and apologies; shards restricted; the beacon-wrong-shore myth is taught beside map-wrongness. Emergency shelter lies remain allowed—unconfessed permanence does not.

## Effect

- Balances Quiet Well mercy with accountability.
- Prevents kind wrongness from becoming Forced-Final doctrine.
- Soft limits: wrong light is not a ferry.

## Notes

Artifact: Well-Beacon Shard. Myth: The Beacon That Called the Wrong Shore.
