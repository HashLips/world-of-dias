# Sketchy Gallery open curation rule

## Name

Sketchy Gallery open curation rule

## Overview

No single patron line may control consecutive major exhibitions beyond one cycle. Funding is welcome; sequence capture is not.

## Description

Curatorial authority rotates through declared windows with mandatory public review notes. Zephan Quell remains final cycle coordinator without becoming a private brand arm. Constant argument over standards is considered healthy—beauty stays civic. The Curator and the Bull myth teaches the comedy of taste fights.

## Effect

- Preserves the gallery as public forum.
- Blocks consecutive capture by one purse.
- Keeps Averra/Sketchy looking plural.

## Notes

Open question: whether “public review notes” can be written so dull that capture still happens in soft language.
