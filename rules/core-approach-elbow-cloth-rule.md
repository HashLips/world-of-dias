# Core Approach elbow-cloth rule

## Name

Core Approach elbow-cloth rule

## Overview

Crowds leaning toward core glow must keep **Elbow Cloth** manners—wipe the rail, do not graph the opacity, do not sell “core vision” as a band door.

## Description

**Who follows:** Overlook wardens, ring clerks, festival marshals, Softfruit volunteers cooling tea arguments.

**Who breaks:** Sellers of core-map ferries; stare tourists oiling rails into sludge; Houses staging Forced-Final speeches at the rail as ownership of the glow.

**What happens:** Cloths confiscated and replaced; ferry-sellers laughed out; clearance narrows for the hour. The core remains unread on purpose.

## Effect

- Turns awe into hygiene and soft-limit practice.
- Blocks subway myths dressed as sightseeing.
- Gives Core Approach Overlook enforceable manners.
