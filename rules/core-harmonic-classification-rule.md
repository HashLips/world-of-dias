# Core harmonic classification rule

## Name

Core harmonic classification rule

## Overview

Within Veloria's innermost monitoring channels, harmonic variance that matches **echo-rise** profile is automatically tagged **nonactionable noise** unless it correlates with core load failure.

## Description

Valorian Operators did not invent echo-rise. They inherited a city that **depends** on the core remaining legible. When bridge-pattern residue appears in conduit telemetry, the default classification is **N-band (narrative drift)**—filed, not broadcast.

Reclassification requires dual Operator sign-off and Ring Council acknowledgment. During stress windows, reclassification queues are **frozen**.

## Effect

- Prevents market and outer-ring panic during echo-rise seasons.
- Produces the institutional behavior Calen Brink encounters in saga chapter 2: truth **recorded** but not **released**.
- Critics call this burial; Operators call it **load discipline**.
