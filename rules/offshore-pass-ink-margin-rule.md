# Offshore pass ink-margin rule

## Name

Offshore pass ink-margin rule

## Overview

Offshore Pass notes written with courtesy ink must **leave smear-margin**—no Forced-Final edge-to-edge flourish that pretends damp air never existed.

## Description

**Who follows:** Averra hosts, pass holders, damp studio guests.

**Who breaks:** Mainland rush writers; sellers of instant-dry pass kits; curators demanding clean edges overnight.

**What happens:** Pass courtesy questioned; ink patience rule cited; messy sleeves as comedy fine.

## Effect

- Extends damp-ink patience onto the pass itself.
- Protects offshore hospitality from mainland tempo.
- Aligns pass, stick, and courtesy rule.
