# Span Toll witness-chip rule

## Name

Span Toll witness-chip rule

## Overview

Talk-token disputes that claim fairness by numbers alone require a **Witness Chip** from a third party before the book closes.

## Description

**Who follows:** Span Toll clerks, Softfruit auditors, Brindle drivers calling foul.

**Who breaks:** Clerks closing books on matching sums without chips; sellers of immunity chips; Houses intimidating witnesses.

**What happens:** Book reopens; fairness-check rule triggered; unsigned chips treated as scrap, not proof.

## Effect

- Puts teeth in toll evidence manners.
- Cousin to nineteen-nineteen checks.
- Blocks pretty math at choke points.

## Notes

Artifact: Span Toll Witness Chip.
