# Tea-house clearance-cooling rule

## Name

Tea-house clearance-cooling rule

## Overview

Before clearance stamps harden a pot-signal quarrel into a closed lane, **tea cooling is offered**—three cups, no winners speech. Temperature before paper.

## Description

**Who follows:** Tea-house hosts, mid-ring wardens, Softfruit mediators.

**Who breaks:** Clerks stamping lanes shut mid-insult; Forced-Final clearance for gossip scores; anyone refusing the tray as “inefficient.”

**What happens:** Stamp delayed; tea rule myth recited; pot-signal mute cousins may follow at night.

## Effect

- Inserts civic cooling between gossip and clearance.
- Protects mid-ring talk from stamp weather.
- Soft limits: tea ≠ ferry.
