# Resonant House echo classification codes

## Name

Resonant House echo classification codes

## Overview

During echo-rise schism season, competing Resonant House factions published **incompatible classification codes** for the same phenomena—without resolving which code was authoritative realm-wide.

## Description

**H-11 (witness tolerance model):** echo-rise and B-band events treated as **managed witness events**; basin-first sharing tolerated as civic hygiene; lockdown discouraged.

**H-19 (pre-fracture stress model):** echo-rise treated as **pre-fracture stress indicator**; core lockdown and voluntary filing silence for unregistered echo-readers recommended.

Both codes reference overlapping telemetry (N-band, B-band, L-band) but assign **opposite public response curves**.

## Effect

- Markets and councils receive contradictory guidance until quorum breaks.
- Social erasure pressure on Calen Brink and witness network under H-19—**not** uniformly enforced after Crown Session and Second Bridge events.

Institutional snapshot only—individual House names remain largely unstated. See [`stories/house-schism.md`](../stories/house-schism.md). Schism **partially unresolved** at Movement Three close.
