# Kiln laughter firing-token rule

## Name

Kiln laughter firing-token rule

## Overview

Shared firings require a **Kiln Laughter Firing Token** when the yard is laughing—proof the clay is for remaking, not Forced-Final mastery flex.

## Description

**Who follows:** Yard keepers, Hearthvale apprentices, Sorel remakers borrowing joy craft.

**Who breaks:** Sellers of “instant mastery” tokens; silent pride firings that ban laughter; Houses treating tokens as guild monopoly.

**What happens:** Tokens void; kiln stays cold for the breaker; second-beginning cousins refuse the flex.

## Effect

- Protects remake joy as workshop law.
- Aligns kiln comedy with Sorel dignity.
- Blocks Forced-Final craft ego.

## Notes

Artifact: Kiln Laughter Firing Token.
