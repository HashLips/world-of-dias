# Scaffold persistence-peg rule

## Name

Scaffold persistence-peg rule

## Overview

Planks marked with a **Persistence Peg** must not receive completion ribbons or Forced-Final clamps. Remove the peg only when the mile agrees the hold is honest.

## Description

**Who follows:** Scaffold crews, Open Hand visitors, F960 etiquette teachers.

**Who breaks:** Foremen bringing ribbon cloth against pegs; Houses declaring becoming “done” for optics; tourists painting permanent lane lines on living planks.

**What happens:** Boards lean; scissors miss; peg rule myth gets recited; clamp ban in recovery is cited. Persistence-scale rule remains the sober twin.

## Effect

- Makes unfinished dignity locally checkable.
- Blocks ribbon theater as virtue.
- Ties myth and artifact to enforceable custom.
