# Scraped correction preference

## Name

Scraped correction preference

## Overview

On measurement ledgers and graph leaves, corrections prefer **scrape** over **erase** so the error history stays legible. A wrong digit that was scraped still shadows the fiber; that shadow is data.

## Description

Calibration Row teaches: if you wipe a page clean, you teach the next hand that certainty was born finished. Scraping leaves a pale scar under the new ink—proof that agreement once lied, or that the maker changed mind.

Orrin Veld’s pocket ledger follows this preference strictly. The **Veld Residual Graph** shows a scrape where a cyan-leaning tick was corrected; the fiber still “remembers” the wrongness—useful when teaching that graphs can look helpful while steering.

The preference pairs with **F840 cold-gap honesty**: name recovery and unfinished quiet; do not clamp every mistake into Forced-Final “done.”

## Effect

- Makes partial publish possible: readers see where law, theory, and taboo guess were revised.
- Undercuts House habits that file wonder as noise by deleting the awkward middle.
- Gives Softfruit field notes and Frame graphs a shared manners language.
