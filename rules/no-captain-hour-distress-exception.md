# No-captain hour distress exception

## Name

No-captain hour distress exception

## Overview

No-Captain Hour **does not mute distress**. Courtesy pins wait; rescue launches. Chaos entertainment never outranks a real call.

## Description

**Who follows:** Pier keepers, listen cousins, Softfruit coastal teachers.

**Who breaks:** Party hosts drowning distress tones; clerks billing before launch during the hour; anyone claiming “no captain means no rescue.”

**What happens:** Distress-before-debt cited; hosts lose pier rights for the week; gratitude hooks still apply later.

## Effect

- Prevents courtesy comedy from becoming lethal.
- Aligns Driftfall joy with rim rescue ethics.
- Soft limits unchanged: rescue ≠ ferry.
