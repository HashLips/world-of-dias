# First-bowl storm-night rule

## Name

First-bowl storm-night rule

## Overview

On storm nights, **First-Bowl Stew Marks order the line—not coin class**. Guests without marks still eat; marks prevent stamp fights, not exclusion.

## Description

**Who follows:** First-Bowl cooks, storm hosts, Softfruit cousins citing shelter-first.

**Who breaks:** Sellers of VIP marks; Houses demanding payment before the first ladle; anyone turning marks into exile tickets.

**What happens:** Kitchen exile for VIP sellers; shelter-first rule cited; marks confiscated and reissued as order chips only.

## Effect

- Sharpens shelter-first into storm practice.
- Blocks Forced-Final class sorting at the bowl.
- Keeps stew marks as manners tools.

## Notes

Artifact: First-Bowl Stew Mark.
