# Third-chair mark visibility rule

## Name

Third-chair mark visibility rule

## Overview

The empty third chair’s **mark stays visible** until a guest sits. Hidden marks and “eternal VIP third chairs” void the hospitality.

## Description

**Who follows:** Verdant hosts, tea-house borrowers, Flagweek overflow tables.

**Who breaks:** Membership sellers; hosts who keep the chair but hide the mark to exclude; Houses rebranding third chairs as donor seats.

**What happens:** Marks reissued; hosts uninvited from Reach tables; third-chair rule cited coldly.

## Effect

- Keeps hospitality furniture honest.
- Blocks VIP cosplay of stranger care.
- Aligns mark and token practice.

Artifact: Verdant Third-Chair Mark.
