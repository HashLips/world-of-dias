# Driftfall no-captain courtesy rule

## Name

Driftfall no-captain courtesy rule

## Overview

During No-Captain Hour, **pins and claims still need courtesy**—absence of a boss is not absence of manners. Floating flags remain; shoving does not.

## Description

**Who follows:** Pier keepers, harbor guests, Flagweek visitors learning water rules.

**Who breaks:** Bullies treating no-captain as free-for-all; coin-weighted pins; Forced-Final ownership speeches on moving water.

**What happens:** Pins sink (fine); floating-flag rule enforced; Softfruit coastal cousins name the bully.

## Effect

- Extends floating-flag ethics into boss-less hours.
- Protects joy chaos from becoming theft weather.
- Keeps pier comedy humane.
