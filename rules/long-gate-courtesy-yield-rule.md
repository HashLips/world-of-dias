# Long Gate courtesy-yield rule

## Name

Long Gate courtesy-yield rule

## Overview

At Long Gate, holders of a **Courtesy Knot** yield once for dignity before stamp arguments escalate. The knot is manners, not a free pass.

## Description

**Who follows:** Gate stewards, Brindle drivers, exile families, fruit-road crews with honest knots.

**Who breaks:** Sellers of “skip-the-gate” knots; travelers who claim knot rights without yielding; Forced-Final clearance speeches that skip the courtesy beat.

**What happens:** False knots are cut publicly; true knots ignored once earn delayed processing and Softfruit-adjacent scorn. The Long Gate Argument myth stays the comedy mirror.

## Effect

- Stages dignity before paper at a moral threshold.
- Cousin to DEB Gate touch manners without replacing them.
- Keeps exile infrastructure human-scale.
