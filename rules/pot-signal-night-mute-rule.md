# Pot-signal night-mute rule

## Name

Pot-signal night-mute rule

## Overview

After courtesy hour, **pot-signal arrays take mute plugs** so gossip tech does not become a shame horn or stare overnight. Wedding warmth may stay; debt-shame pots get plugged hard.

## Description

**Who follows:** Array Court wardens, lane keepers, Softfruit neighbors reclaiming sleep.

**Who breaks:** Houses blasting bulletins all night; vendors running shame-pots for unpaid tabs; tourists treating arrays as always-on entertainment.

**What happens:** Wardens seat mute plugs; repeat offenders lose ledge rights for a week; Softfruit comedy names the breaker in morning pots. Distress-listen cousins on the rim are exempt—this rule is civic gossip, not rescue silence.

## Effect

- Keeps everyday resonant tech loveable.
- Separates manners mute from censorship panic.
- Gives mid-ring nights a enforceable quiet without banning dawn talk.
