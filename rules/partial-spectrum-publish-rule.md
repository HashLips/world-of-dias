# Partial spectrum publish rule

## Name

Partial spectrum publish rule

## Overview

Spectrum claims released to the Velorian basin must stay **partial on purpose**: they carry no-ferry disclaimers, and they separate **law** (what instruments repeatedly show), **theory** (what the maker believes), and **taboo guess** (what must not be sold as a door).

## Description

Born from Row craft and formalized when **Issa Partial** and **Orrin Veld** released the partial spectrum packet after the Caliburn crisis. The rule does not ban talking about background bands (F120, F380, F610, F840, disputed F960). It bans packaging those talks as:

1. a subway map between realms,
2. a promise that a residual seam is a usable window forever,
3. a claim that Frequency Zero or Frederick’s crossing has been solved.

A compliant release labels each section. Softfruit folk data may sit beside Frame graphs if both are marked as evidence types. Incomplete teaching models of the Spectrum Frame are preferred over “complete” widen instructions.

Archivist Pellun’s **partial courtesy shelf** is the institutional cousin: file incomplete honesty where readers can find it, without pretending the stamp “nonactionable” erased the world.

## Effect

- Keeps Calibration Saga science aligned with Dias soft limits.
- Lets schools teach “counted sky” columns without inventing ferries.
- Gives Operators a paperwork language for “this is true enough to warn, not true enough to escort.”
