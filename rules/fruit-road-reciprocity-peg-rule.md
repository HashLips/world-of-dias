# Fruit-road reciprocity-peg rule

## Name

Fruit-road reciprocity-peg rule

## Overview

Reciprocity pegs must notch **given and taken**. Pegs that only notch “taken” get snapped; kindness is not a House career, but theft-by-tally is still theft.

## Description

**Who follows:** Orchard crews, waystation stewards, Wired Bloom cousins.

**Who breaks:** Carts that only take; sellers of peg membership clubs; Forced-Final “we’re owed” speeches without mend marks.

**What happens:** Pegs snapped in Softfruit comedy courts; soup tags and bloom markers refuse the breaker; harvest rule cited.

## Effect

- Makes reciprocity tally enforceable.
- Blocks one-way ledgers dressed as ethics.
- Aligns road and Wabet manners.
