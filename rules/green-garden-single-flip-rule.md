# Green Garden single-flip rule

## Name

Green Garden single-flip rule

## Overview

Minute sand **flips once per task**. Endless flipping to keep “improving” is a stare dressed as stewardship.

## Description

**Who follows:** Lane keepers, third-chair hosts, children learning border-box care.

**Who breaks:** Forced-Final gardeners; tourists flipping without looking; Houses scheduling endless improvement crews.

**What happens:** Peacocks and Softfruit commentary; minute discipline rule cited; sand confiscated for the day.

## Effect

- Gives minute discipline a physical limit.
- Cousin to silence-bead and anti-stare.
- Protects living soil from endless looking.
