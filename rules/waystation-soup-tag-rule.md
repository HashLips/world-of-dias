# Waystation soup-tag rule

## Name

Waystation soup-tag rule

## Overview

Shared waystation soup asks for a **Soup Tag**—labor, peel, or mend credit—before second bowls. First hunger still eats; freeloading as lifestyle does not.

## Description

**Who follows:** Waystation cooks, caravan kids, Softfruit auditors on friendly days, Wired Bloom crews passing through.

**Who breaks:** Wishful handbill sellers promising eternal free soup without tags; carts that only notch “taken” on reciprocity pegs; Houses turning tags into VIP class tickets.

**What happens:** First bowl may still be given; second bowl waits on a tag. Pegs that never “give” get snapped in Softfruit comedy courts. Handbill fraud earns empty crates and better stories about the seller.

## Effect

- Makes fruit-road reciprocity chewable.
- Separates emergency feed from entitlement theater.
- Aligns with restoration-before-pick cousins.
