# Quiet Well map-wrongness rule

## Name

Quiet Well map-wrongness rule

## Overview

Public maps of Quiet Well and sister oases must remain strategically wrong. Accuracy is rationed to Keep assent, not to market demand.

## Description

Silent Dune Keep maintains decoy marks, rotated true paths, and penalties for publishing clean water charts. The rule treats cartography as extraction technology.

## Effect

- Preserves oasis longevity under caravan pressure
- Creates conflict with Nauw fruit-money and Basin surveyors
- Makes “finding the well” a moral plot, not only a navigation plot
