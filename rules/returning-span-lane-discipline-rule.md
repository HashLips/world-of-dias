# Returning Span lane discipline rule

## Name

Returning Span lane discipline rule

## Overview

Crossing the **Returning Span** requires a declared lane choice and pass logging. Curiosity must pick a path—then walk it.

## Description

Travelers commit to first, second, or third lane behavior profiles before entry. Unlogged switching during drift windows is high-risk negligence. The **Curious Arch** marks the commitment moment; lane tokens remind hands what they chose. Near-return drift makes undeclared changes especially costly—pattern rhyme without a log becomes collision weather.

## Effect

- Increases repeat-route reliability.
- Feeds Refrain Walker forecasts with structured data.
- Turns “I’ve seen this before” into accountable craft.

## Notes

“Unmarked lane change” is a common Span incident root. Open question: whether a fourth lane rumor is etiquette failure or true unfinished becoming.
