# Rival-dial argument rule

## Name

Rival-dial argument rule

## Overview

When rival dials agree too quickly, **treat the agreement as suspect** until they quarrel into a usable middle. Fast consensus is not Forced-Final truth.

## Description

**Who follows:** Row apprentices, Noro Halfmeasure kit users, Orrin chalk cousins.

**Who breaks:** Hands clamping “done” when needles smile together; Houses demanding single-dial certainty; anyone silencing the quarrel.

**What happens:** Runs voided; oilvine apology if tools were forced; twin-dial myth assigned.

## Effect

- Institutionalizes Halfmeasure honesty as rule.
- Blocks pretty agreement as science.
- Pairs with ask-again culture.

Artifact: Halfmeasure Rival Dial. Myth: The Dial That Argued with Its Twin.
