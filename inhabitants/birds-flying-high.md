# Birds Flying High

## Name

Birds Flying High

## Overview

**Birds Flying High** is a non-human Aelwyn presence: a large calm blue avian with long legs and a habit of carrying a small path-key, used in canopy talk to teach that height still owes the hills a soft landing.

## Description

Plates show a rounded mid-blue body, a darker folded wing, a sleepy white-slit eye, and legs long enough to thread a yellow crescent season-mark before the feet find layered hill ground. The tiny black key at the beak is the detail path-keepers argue about most: some say it opens only canopy slits that have already agreed; others say it is a reminder-token, not a master key. Either way, stealing the key from a living bird is bad craft. Locals treat the inhabitant as neighbor-shape, not Earth wildlife inventory. Children are told that if you see the long blue legs still touching hillcrest, the flight is honest; if the feet leave and the key swings like a boast, wait for a quieter messenger. Temper is usually calm. Hunger talk varies. Manners stay: pass through fruit-signs without kicking them, return keys, and do not confuse height with permission to ignore ground care.

## Notes

Non-human canopy neighbor. Height with ground touch. Dias name, not an Earth song.
