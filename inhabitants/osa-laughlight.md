# Osa Laughlight

## Overview

**Osa Laughlight** hosts Hearthvale breakfasts that feed strangers without opening a ledger—joyful anchor for exile mornings.

## Description

Stew-onion breath, Laughter Week banners stored between seasons, a table that holds Flagweek-style even when flags elsewhere flip. Osa will refuse costume remaking talk until after the bowl.

## Beliefs About Them

Mutual Table hands treat Osa as cousin infrastructure. Free-Captains who try to recruit from Osa’s table get laughed out kindly once, coldly twice.

## Narrative Role

Joyful anchor—second beginning as food first.

Tag: joyful anchor / locale color. Saga-ready only if a chapter needs a table, not a sword.
