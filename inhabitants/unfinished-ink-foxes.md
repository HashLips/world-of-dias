# Unfinished Ink-Foxes

## Overview

Unfinished Ink-Foxes are medium foxes whose pawpads leave temporary ink-dark prints that fade as if the world undoes them.

## Description

Playful thieves of brushes and straps. Bite if cornered. Prints are famous.

## Beliefs About Them

Following ink prints teaches route patience.
