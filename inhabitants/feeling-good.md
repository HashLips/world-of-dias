# Feeling Good

## Name

Feeling Good

## Overview

**Feeling Good** is a Nauw Outer Rim Seas non-human presence: a dark white-eyed figure-form that appears when cheer runs hot, bringing white ribbon-tethers and a serpentine watcher so good feeling stays answerable to path and pier.

## Description

Witnesses describe a featureless dark torso with sharp white eyes, white bands crossing chest and arms, and a larger dark serpentine presence with one eye and a clawed hand hovering near. Sometimes only the ribbons are felt—soft resistance when a celebration wants to tip into harm. The golden path in plates is the courtesy exit back to work; the sworded islet is a reminder that some conflicts already ended and should stay planted. Locals do not file Earth pop-song readings. They file a neighbor-mood that needs manners: accept the tether, greet the watcher, walk the yellow line home. Temper is intense and brief. Bad craft is cutting the ribbons for a freer thrill.

## Notes

Non-human tethered cheer. Dias name, not an Earth lyric.
