# Echo-Band Elk

## Overview

Echo-Band Elk leave tracks that sometimes print twice—once firm, once faint—as if a prior walk still leans on the soil.

## Description

Large elk, pale coats. Peaceful unless cornered. Track double is the signature.

## Beliefs About Them

Hunters argue which print to trust; elders say both.

## Narrative Role

Large F120 wonder.
