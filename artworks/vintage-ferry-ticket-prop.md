# Vintage Ferry Ticket Prop

## Name

Vintage Ferry Ticket Prop

## Overview

*Vintage Ferry Ticket Prop* is a worn comedy stub for one crossing between frequency bands—cheerful print, struck boat mark, and fine print that returns you to the dock you already stand on.

## Description

Aged cream ticket with torn edges: Captain Ell Ferrylie’s Fake Band Ferry Ticket from Ferrylie Joke Pier, Nauw. “Good for one crossing / between frequency bands,” dock 3, fare one Dias mark, serial No. 041972, Ell’s signature. A red prohibition slash over a steamboat silhouette; bottom box: *Destination: nowhere you do not already stand* / *Not legal tender for any Operator escort.*
