# Pale Pink, Already Washing Off

## Name

Pale Pink, Already Washing Off

## Overview

*Pale Pink, Already Washing Off* is Second Crossing Lane Chalk. Pale pink dust. Temporary courtesy lanes. Already washing off. Not paint. Not a map.

## Description

Pale pink dust marks temporary lanes so arrival and return can share the span without Forced-Final shoving. It washes off in rain on purpose. The plate shows it already washing. The lines are dust, not a coat of paint. Using permanent paint is arrogance toward unfinished weather. There is no permanent paint here.

It is not a map. No legend, no named road, no chart. Yard kids redraw after storms. The kids are not in the frame. The dust is, and it is leaving.

When the chalk is honest, the rose keeps time. The rose is not a second subject required in this plate. The chalk is the artifact. Pale pink. Temporary. Washing off.
