# Game with Destiny

## Name

Game with Destiny

## Overview

*Game with Destiny* is a Bloomline Estuary night-table plate: golden hands play identical crown-marked cards beside a blue-tipped cigarette—the estuary lesson that destiny-talk is still a game of shared marks, not a solo prophecy.

## Description

Charcoal-gray table surface, lighter upper band. Two solid golden-yellow arms from bottom: right hand fans five off-white navy-bordered cards each centered with the same blocky black crown/claw/mountain silhouette; left hand places or adjusts a face-down card. Upper left: irregular black oval ashtray over bright orange-red spill/glow; white cigarette with bright blue tip and glowing orange cherry; thin jagged red smoke line rising. Late-night, clandestine focus. Flat mid-century graphic.

An estuary artifact plate: play the same marks face-up enough to keep destiny from becoming a private cheat.
