# Blink Against Bright Dunes

## Name

Blink Against Bright Dunes

## Overview

*Blink Against Bright Dunes* is a digital image study of Dune-Glass Lizards nearly unseen on sand.

## Description

Translucent lizards crawl bright dune faces—glasslike scales letting sand color through, dark bead eyes as the giveaway blink. Soft gold dunes, no travelers.
