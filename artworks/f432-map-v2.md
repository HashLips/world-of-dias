# F432 Map V2

## Name

F432 Map V2

## Overview

*F432 Map V2* is the **current** macro map artwork for the F432 frequency realm—the latest clarity pass after the early survey and *F432 Map V1*.

## Description

Parchment-style chart titled **F432**, showing the three major lands (Wabet west, Nauw northeast, Sorel southeast) with Calareth and Averra between the waters. Labels include Aelwyn Canopy, Verdant Reach, Lumira Sands / Quiet Well, Eastbound Fruit Road, Veloria City in the Velorian Basin, Brindle March, Glasswater Fields, Long Gate, Hearthvale / Secondfire, Driftfall and Claimscar, Flagweek Strip, and related roads and seas.

Asset reference: `assets/f432-map-v2.jpg`.

## Real-World Role

**Latest visual standard** for F432 geography in worldbuilding, presentations, and repository navigation. Prefer this file over V1 when showing “where things are now.”
