# That Forest

## Name

That Forest

## Overview

*That Forest* shows a black prone silhouette on vivid royal-blue ground beneath endless leafless grey trees fading into pale sky.

## Description

Atmospheric layers of skeletal trunks. The blue floor is the shock—too saturated to be ordinary soil. The figure lies limp, face-down, as if the listening finished them.

## Real-World Role

A desolate forest stage for Dias place-memory.

## Lore Connection

Visual for **Blue Litter Underwood**: groves where resonance puddles as blue litter underfoot and travelers drop mid-listen. Wabet calm is not always gentle; some canopies ask too much.
