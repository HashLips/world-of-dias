# Lemon Tree

## Name

Lemon Tree

## Overview

*Lemon Tree* is a purple-field specimen: straight red stem, short red branch up-right, twenty-odd bright yellow ovals with tiny white gloss marks and orange-red nubs at attachment, all backed by a jagged dark-brown contour shadow.

## Description

Pods vary in size but share the same smooth graphic. No leaves beyond the stem logic. Tiny white mark top-right. Mood is ordered abundance, slightly alien, harvest-ready.

Asset reference: `assets/lemon-tree.jpg`.

## Real-World Role

A flora plate for prized yellow pods on a red nutrient line.

## Lore Connection

Aelwyn Canopy treats Lemon Tree as the red-stem yellow-pod growth taken in counted pairs, never stripped bare in one pass. Local rule: leave the jagged brown shadow-line of unpicked pods visible so the tree still reads whole. Resonance prefers glossy pods picked cool. Shaking the stem for speed bruises the white highlights into dullness.
