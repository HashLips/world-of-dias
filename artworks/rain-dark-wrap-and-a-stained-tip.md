# Rain-Dark Wrap and a Stained Tip

## Name

Rain-Dark Wrap and a Stained Tip

## Overview

*Rain-Dark Wrap and a Stained Tip* is a Difference Mark Stylus. The body is bone or darkwood. A soft wrap has gone dark with rain and thumb. The tip is stained with chalk, ash-ink, or the Span's own damp. It is not a key and not a weapon.

## Description

The stylus is short. Bone or darkwood makes the hard point. A soft wrap takes the grip, darkened by rain and by the thumb that has already used it. The tip is stained. The stain is chalk, ash-ink, or the Span's own damp, the marks the entry already allows the tip. The line such a tip leaves is narrow, the sort that fits on a chip in a milestone, not an epic down a wall.

What the point is for, in the account, is offsets. Hinge count, bell tone, which way a moss edge lagged. The plate does not turn those offsets into a readable sentence, and it does not pretend the marks were always one memory. Twin styluses are sold as jokes and used as serious pairs, one for the last pass and one for this one. This frame keeps to the one tool: wrap, body, stained tip.

Bright rings are not part of this record. The stylus is not a key, not a weapon, and not a loop-needle. Nobody is shown whistling it unused in a pouch, which the Keepers would notice and the plate does not stage. The tool stays cheap and particular. The hand is elsewhere.
