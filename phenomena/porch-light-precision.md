# Porch Light Precision

## Name

Porch Light Precision

## Overview

**Porch Light Precision** is the folk name for inviting nests by measuring too well—leaving a bright, careful instrument on through the hour when manners say glance and close. Like a porch lamp that calls moths, a Frame left “just a little longer” calls seams and what seams host.

## Description

The metaphor is practical: Bleed Weather shutters, F610 anti-stare manners, and Row craft all agree that some looking should end. When Orrin’s Spectrum Frame keeps graphing past polite window length, the residual seam behaves like a porch light left on—brightness that outlasts the task and invites company.

Warden Brusk uses the phrase as warning against sky-aimed instruments. Softfruit vendors use it as joke (“your dial is a porch light; expect moths”). Publish footnotes use it to explain why incomplete Frames are safer teaching tools than “one more widen.”

## Conditions

Named after high-precision multi-band runs, forced widening attempts, and any night someone treats a residual seam as an endless reveal window. Not limited to Orrin’s alcove—any careful instrument can earn the insult.

## Cultural Interpretations

- **Caution:** precision is not free; turn the light off.
- **Comedy:** moths, seam-moths, static cats arranging themselves on benches.
- **Tragedy (saga):** the Caliburn arrives as helpful amber because the light stayed on.
