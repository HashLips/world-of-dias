# Residual Calibration Seam

## Name

Residual Calibration Seam

## Overview

A **Residual Calibration Seam** is a narrow persistence of reveal-pressure inside F432 after an instrument should have gone opaque again. The famous instance is the seam left by Orrin Veld’s **Spectrum Frame**—the crack that made the Caliburn’s nest legible.

## Description

Witnesses describe a hairline brightness in glass or air that does not behave like ordinary lamp glare. Numbers near it agree too quickly, then drift. Unlike F610 reveal windows (timed, disciplined), a residual seam **outlasts the window** and invites nesting.

What it is, plainly:

1. The Frame graphs background-band signatures from inside F432.
2. A polite run should end; the glass should dull.
3. Instead a bright seam remains—porch-light precision.
4. That persistence is where the Caliburn becomes readable as helpful amber in the lattice.

What it is not: a subway portal, Frequency Zero, or an endless F610 research window. The **residual seam non-window rule** exists because apprentices keep wanting it to be those things.

## Conditions

Appears after high-precision multi-band graphing against load-noise backgrounds; more likely near Veloria’s multi-realm core adjacency. Forced widening makes it hungrier. Clean refusal and incomplete instruments starve it slowly, not instantly. Vault attempts may fail if the nest has already learned the room.

Typical saga timeline: first too-perfect agreements → seam will not close → Caliburn visible → widen temptation → vault/break → seam’s host escapes into city noise while the Frame is left deliberately incomplete.
