# Tea-Tray Temperature Drop

## Name

Tea-Tray Temperature Drop

## Overview

**Tea-Tray Temperature Drop** is the quarrel-heat falling when three cups arrive without winners—civic cooling felt as room temperature, not metaphor only.

## Description

Faces unclench; pot-signal insult volume drops; clearance stamps wait. Can be faked with AC and silence orders—hosts know real drop by whether laughter returns kind.

## Conditions

Third-Ring Tea House during ring-block fights; after dawn murmur misunderstandings. Weak if lids were pulled for slogans all morning (hunger fury upstream).

## Cultural Interpretations

- **Tea hosts:** manners working.
- **Clerk:** delay tactic; stamp anyway.
- **Softfruit:** temperature before paper.
- **Hazard:** drop ≠ erased conflict forever.
