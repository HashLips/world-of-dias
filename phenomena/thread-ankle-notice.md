# Thread-Ankle Notice

## Name

Thread-Ankle Notice

## Overview

**Thread-Ankle Notice** is the body-first tickle when DEB Gate’s dawn thread brushes the ankle—crossing felt before clerks speak.

## Description

Attention drops from paper to feet. Geese quiet if the touch is honest; hiss if efficiency cut the line. Children learn “feel before stamp” as sensation, not slogan.

## Conditions

Dawn-strung threads; Flagweek crowd repairs; Softfruit teaching days. Missing when clerks cut thread for surge throughput (and the gate feels wrong all morning).

## Cultural Interpretations

- **Keepers:** threshold awake.
- **Efficiency clerk:** delay; remove it.
- **Softfruit:** body manners.
- **Hazard:** notice ≠ full clearance granted.
