# Gratitude-Hook Return Tug

## Name

Gratitude-Hook Return Tug

## Overview

**Gratitude-Hook Return Tug** is the later line-pull when rescue is answered as favor, not invoice—reciprocity arriving as weight on the hook.

## Description

Listen posts hang returned hooks as trophies. Subscription rescue sellers never feel the tug—only sticky coin. Softfruit teaches the difference with fish dinners.

## Conditions

After distress-before-debt launches; years-later paybacks; quiet rim seasons. Weak when debt theater billed the first launch.
