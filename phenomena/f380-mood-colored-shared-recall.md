# F380 Mood-Colored Shared Recall

## Name

F380 Mood-Colored Shared Recall

## Overview

**Definition:** In F380, how a group remembers a shared hour often takes color from the communal affect-climate of that hour. Memory is not only private; climate helps shape what is kept and how it feels when retold.

## Description

After a hearttide shift on Bloomline, people may retell the same event with matching warmth, mute, or edge that tracks the weather they shared—not only the factual sequence. Tidehearts and attendants notice when recall is climate-tinted. One person blaming themselves for a climate-scale tone misfiles the band: private guilt is not the same as communal memory weather.

This does not mean everyone gets identical perfect transcripts. It means shared feeling participates in what sticks. Softfruit hearttide interviews measure “how it felt” without claiming a Veloria hall has become F380.

## Conditions

Strongest after shared estuary or crowd hours with clear affect weather. Weaker for solitary tasks held in hush. Forced cheer or forced grief as a memory tool is manners failure and usually false.

## Cultural Interpretations

Hearttide attendants: separate private blame from climate recall. Softfruit: interview without conversion claims. Band Confusion Corrections: not “everyone cries rainbows into the past.” Houses: Observation for retell patterns; Theory for models of coupling.
