# Workshop Tool Habit Echo

## Name

Workshop Tool Habit Echo

## Overview

The stubborn preference of tools and benches to continue yesterday’s motion, grip, and tempo until a maker teaches them today’s task.

## Description

Open Hand makers and Averra studios know chisels that “lean” toward an old cut. Teaching a tool takes repetition and sometimes a spoken reset—craft courtesy, not a spell. Ignoring habit echo spoils work and fingers.

## Conditions

Strongest on beloved tools with long single-owner use. Shared shop tools carry mixed habits and need clearer resets.

## Cultural Interpretations

Makers: daily truth. House technicians: classify as minor resonant artifact behavior when severe. Softfruit: cousin to dough memory.

## Notes

Exemplar of ordinary echo under the foundational principle—wonder without omnipotence.
