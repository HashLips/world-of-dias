# Pot-Signal Night Mute Plug

## Name

Pot-Signal Night Mute Plug

## Overview

A **Pot-Signal Night Mute Plug** softens array hum after courtesy hour so gossip tech does not become a stare or a shame horn overnight.

## Description

Cork-and-reed plug with a dulling bead; fits common ledge pots. Customs say mute is manners, not censorship—wedding pots may stay warm; debt-shame pots get plugged hard.

## Cultural Meaning

Civic resonant etiquette. Beauty of a quiet street that still remembers how to talk at dawn.

## Usage

Array Court wardens, lane keepers, Softfruit neighbors reclaiming sleep; never used to mute distress listen cousins on the rim.
