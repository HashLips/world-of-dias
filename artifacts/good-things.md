# Good Things

## Name

Good Things

## Overview

**Good Things** is a kept Nauw Outer Rim Seas path kit: a mint trailing scarf and an orange shadow-cloth used when walkers carry gifts so afterimages stay honest on the gray road.

## Description

The mint scarf ties loosely and trails; if it will not trail, the gift is probably clutched too hard. Orange shadow-cloth lays behind the walker in drills to mark cost and wake. Pier hosts use the kit before fruit runs and guest deliveries. Ignoring the orange mark while boasting of good things is emptied craft. Dias name only.

## Cultural Meaning

Outer Rim likes gifts that admit their wake.

## Usage

Path deliveries, guest thank-you walks, and apprentice carry drills. Lent as scarf-plus-shadow pair.

## Notes

Path-gift kit. Trail mint; own the orange wake.
