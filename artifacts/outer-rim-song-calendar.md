# Outer Rim Song Calendar

## Overview

An **Outer Rim Song Calendar** is weather and whale-route knowledge held as song—hard to forge well, easy to mishear if you treat it as tourist sheet music.

## Description

Not always paper: knot-cords, loft boards, voice-memory. Written copies exist for ferry windows and child teaching. Wrong notes fail in storm faster than wrong ink fails in court.

## Cultural Meaning

Song as civic time. Reliability is practice, not stamp.

## Usage

Investigation: when a check-in should have sounded; which tide a Deep-Keel rumor rode; teaching Softfruit visitors humility.
