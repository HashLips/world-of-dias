# Kiln Laughter Firing Token

## Name

Kiln Laughter Firing Token

## Overview

A **Kiln Laughter Firing Token** grants a place at a shared firing when the yard is laughing—proof the clay is for remaking, not Forced-Final pride. Second-beginning craft made portable.

## Description

Fired clay disc with a smile-crack glaze; warm after successful firings. Selling tokens as “instant mastery” voids yard goodwill. Sorel cousins borrow the joke when exile craft needs a new start.

## Cultural Meaning

Joy as workshop manners. Beauty of a cracked glaze that still holds.
