# Ring-Pass Wafer

## Name

Ring-Pass Wafer

## Overview

A **Ring-Pass Wafer** is a thin resonant disc that hums a licensed clearance tone for one Veloria ring-lane window. Echo-aware personal craft—not a phone, not a subway ticket between bands.

## Description

Palm-sized, faintly warm, etched with a measure-mark cousin. Failures include wrong-tick itch, sealed load silence near core opacity, and stare risk if held against glass too long. Civilians hold day-wafers; clerks and licensed makers hold longer ones. Selling “band ferry wafers” is a pier joke that gets you laughed out of Softfruit.

## Cultural Meaning

Ring clearance made portable without pretending the wafer is omniscience or a door out of F432.

## Usage

Shown at mid-ring gates and overlook rails; powered down after the window; never used as Forced-Final ID for strangers’ lives.

## Notes

Holders: ring clerks, licensed makers, rare civilians. Place: Core Approach Overlook / mid-ring gates. Soft limits: no ferry; Zero unresolved.
