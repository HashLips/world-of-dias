# Ashen Rest Relay Horn

## Name

Ashen Rest Relay Horn

## Overview

An **Ashen Rest Relay Horn** sounds a short rest-viable call when a hearthline stop can still take bodies without collapsing. Not a panic trumpet—more a porch-light cousin for tired roads.

## Description

Ash-dulled brass; ponies know the tone. Blown too often for vanity and the relay ignores you. Paired with shelter-first manners from Hearthvale when storms lean.

## Cultural Meaning

Rest as infrastructure. Soft limit against Forced-Final “push through” speeches.

## Usage

Relay keepers; pony handlers; Outer Rim crews learning basin rest craft.
