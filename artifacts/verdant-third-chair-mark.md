# Verdant Third-Chair Mark

## Name

Verdant Third-Chair Mark

## Overview

A **Verdant Third-Chair Mark** tags the empty seat kept warm for a stranger—hospitality craft under the third-chair rule. Not a VIP reservation ribbon.

## Description

Moss-dyed cloth strip; ties to chair back; removed when the guest sits. Selling “eternal third chairs” as membership is comedy that gets you uninvited.
