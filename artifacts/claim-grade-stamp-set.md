# Claim Grade Stamp Set

## Name

Claim Grade Stamp Set

## Overview

Four stamps—**Law**, **Theory**, **Observation**, **Careful** (taboo guess)—used by House juniors and borrowed by Softfruit teachers to grade cosmic claims in public without pretending all sentences weigh the same.

## Description

Hardwood block with four faces or four separate handles, ink colors deliberately dull so beauty does not sell false authority. The Careful stamp often carries a Partial Echo Slash motif. Lost sets are replaced uglier on purpose.

## Cultural Meaning

Epistemic manners made portable. A cousin to Clerk Partial Echo Stamp, aimed at cosmology rather than single echo readings.

## Usage

Intake desks; Softfruit orientation; Averra exhibits labeling wrong maps; gate booths when ferry talk needs demotion.

## Notes

Stamping Law as a joke is a sackable offense in Houses and a ladle-ban in Softfruit.
