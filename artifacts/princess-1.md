# Princess

## Name

Princess

## Overview

**Princess** is Coral Strand dance-crown craft: a white mask-base with black eye-slits, seven orange finger-pillars tipped in magenta ovals ringed cyan, and a dark brown dancer silhouette kept as the honest motion on that crown.

## Description

Strand workshops build Princess as a standing craft and a painted board. The white semicircle base must show both black eye-marks; the seven pillars must stay countable; each magenta oval keeps its thin cyan border so the tips read as living measures, not bare knobs. The dancer is cut or painted mid-pose—one leg bent, arms open—with a slight orange offset allowed as vibration. Local care forbids using the craft to crown a bully, and forbids renaming the tips as private jewels. Resonance is dance against watching base; memory is the seven-count; wonder is cyan on magenta under pale pink telling light. Pieces travel between strand halls and return with ovals unchipped. Soft talk that files Princess as Earth royalty costume is set aside; on the Strand the name is the dance-crown hour.

## Cultural Meaning

Along Coral Strand, Princess means offered motion on a watching crown—not dominion over neighbors.

## Usage

Hall crafts, festival readiness boards, and teaching silhouettes. Not a throne prop for forced bows.
