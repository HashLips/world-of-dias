# Margin Scrape Blade

## Name

Margin Scrape Blade

## Overview

A **Margin Scrape Blade** is a thin bone-or-brass scraper used to lift ink without erasing the scar of a wrong stamp. It keeps margin alive so corrections can be read as history, not silence.

## Description

Flat, slightly curved edge; often chalk-dusted; never sharpened like a weapon. Apprentices learn scrape-before-stamp-over. The stamp-that-ate-its-margin myth is the nightmare of clerks who threw their blades away.

## Cultural Meaning

Honesty tool against Forced-Final paper. Scraped ledgers outrank pretty silence.

## Usage

Held by copy-desk juniors, Archivist apprentices, and Row makers amending publish margins; forbidden in some House rooms that worship clean pages.
