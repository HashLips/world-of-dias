# Future Wizard

## Name

Future Wizard

## Overview

**Future Wizard** is a kept Mercer Shed sequence kit: three hand-panels (or cards) showing marked scrap, lit match, and empty pinch, used so apprentices cannot skip to clever futures without mark, revision fire, and release.

## Description

Yellow, red, and purple hand tokens (or printed panels) hang in order. The scrap must carry a real working mark before the match card may move. The empty pinch is celebrated only after ash or discard is honest. Shed talk rejects Earth wizard-robe theater; this is workshop manners for tomorrow’s tools. Selling the match panel alone as edgy décor empties the craft.

## Cultural Meaning

Mercer Shed treats future skill as a sequence you can still reverse-read.

## Usage

Apprentice project gates, guest tool inductions, and revision nights. Lent as a three-part set only.

## Notes

Craft-sequence triptych. Mark, flame, empty.
