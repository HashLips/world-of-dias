# Second Crossing Lane Chalk

## Name

Second Crossing Lane Chalk

## Overview

**Second Crossing Lane Chalk** marks temporary courtesy lanes so arrival and return share the span without Forced-Final shoving. When the chalk is honest, the rose keeps time.

## Description

Pale pink dust; washes off in rain on purpose. Yard kids redraw after storms. Using permanent paint is considered arrogance toward unfinished weather.

## Cultural Meaning

Traffic beauty. Discipline without clamps.

## Usage

Yard wardens; fruit-road marshals; Softfruit volunteers on festival days.
