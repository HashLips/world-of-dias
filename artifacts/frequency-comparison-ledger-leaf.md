# Frequency Comparison Ledger Leaf

## Name

Frequency Comparison Ledger Leaf

## Overview

A single durable ledger leaf (or chapbook center-fold) that compares the eight established frequencies on one page—fundamental difference, one time/change tell, one soft-limit warning—plus a thin Present-Age marker strip. Not a ferry timetable.
