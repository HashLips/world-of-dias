# Familiar

## Name

Familiar

## Overview

**Familiar** is a kept F960 recognition token: an orange-red portrait card with mint hat-glasses marks and lime accents used when a neighbor-look feels already known and still needs a proper greeting.

## Description

Cards or shallow reliefs show the half-lidded orange face, mint frames, lime living lines. Hosts place them at guest doors so arrivals remember: recognition is not a free pass into private rooms. Frequency talk rejects Earth “familiar spirit” readings; this is neighbor craft. Overusing the token to claim intimacy empties it. Returning a borrowed card without wiping dust from the mint brim is a mild shame.

## Cultural Meaning

F960 likes warmth that still knocks.

## Usage

Guest door shelves, apprentice neighbor drills, and quiet reunions. Lent with a spoken greet-rule.

## Notes

Recognition token. Known face; still ask.
