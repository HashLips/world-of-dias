# Respect Thrown

## Name

Respect Thrown

## Overview

**Respect Thrown** is an F960 bell-and-spike set: two orange-yellow bells on a thin blue hang-line above black blade-spikes tipped with white dots—respect offered as careful sound, never as a crash into the teeth.

## Description

Realm workshops string the twin bells on blue thread so they hang close and bright. The spike row stays part of the full craft: black blades, white round tips, teal-grey mound behind. You do not remove the spikes to make the bells "safer looking." Local care says the throw of respect is a measured ring with the line steady; flinging bells into the spikes for noise is the named failure. Resonance is gold against mint and black; memory is the white tips; wonder is how delicate the blue line looks over danger. Sets return with shine-marks clean and dots intact. Soft talk that treats the name as empty sarcasm misses the realm rule: respect is thrown soft, above the blades.

## Cultural Meaning

In F960, respect thrown means sound given carefully over a ground that can cut.

## Usage

Hall sets and readiness displays. Not a smash toy.
