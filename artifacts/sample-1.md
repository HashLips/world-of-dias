# Sample

## Name

Sample

## Overview

**Sample** is Elder Shelf measure-lounge craft: a bright red tall-back spindly chair paired with a black lounge silhouette bearing a royal-blue square where a head would be—rest that still displays a clear sample measure.

## Description

Shelf rooms keep the red chair thin-legged on purpose so shadows stay sharp and honest. The blue square is the sample—solid, featureless, centered between elbows in the plate. Black lounge posture (hands behind neck, ankles crossed) is the care model for not rushing the measure into a fake face. Local care forbids painting eyes on the square for comfort, and forbids using the set to mock someone resting. Resonance is blue measure on red seat; memory is the long tan shadows; wonder is how calm a square can be. Chairs return with legs true. Soft talk that treats Sample as unfinished error misses the Shelf rule: the sample is complete as a square.

## Cultural Meaning

On Elder Shelf, a sample is a held blue measure at rest—not a person you get to invent.

## Usage

Quiet rooms and teaching lounges. Not a joke chair for forced posing.

## Notes

Named for the measure rest. Pair with the artwork plate in assets.
