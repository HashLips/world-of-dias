# Egg Run

## Name

Egg Run

## Overview

**Egg Run** is a kept F120 teaching kit: a white pace-bird stand-in, pink shell tokens, and an orange grasp-figure used when a new echo must learn motion by contact and then let go.

## Description

The bird piece is large and simple, legs webbed for “ongoing walk.” The orange figure is light and clamp-handed for drill. Shell fragments stay on the cloth so nobody pretends the break did not occur. Instructors time the release: hold long enough to catch pace, not long enough to halt the bird. Frequency guests who treat the kit as a cute hatch story without the release rule are corrected. The artifact is about first contact manners, not ownership of what hatched.

## Cultural Meaning

F120 wants new forms mobile and untrapping.

## Usage

Apprentice echo drills, guest first-day orientations, and quiet hatch aftercares. Lent as full set.
