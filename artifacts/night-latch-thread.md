# Night-Latch Thread

## Name

Night-Latch Thread

## Overview

A **Night-Latch Thread** is a dark thread tied on a latch. It deepens to near-black if the latch is tried in the night. It watches a door. It does not follow a traveler.

## Description

Spun dull red by day, easy to mistake for mending thread. Knotted on a latch or a shutter bar, it drinks color when metal is tested by a hand that does not live there. Morning shows the darkening. It does not identify the hand, sound an alarm, or hold the door shut. A household still has to wake up.

## Cultural Meaning

Outer-ring practicality: a sign you can read without owing a guild. Farstock sells it beside ordinary thread so nobody has to whisper.

## Usage

Homes, workshops, the shop’s own back shutter. Useless on a road and dishonest if worn as jewelry; on a wrist it only darkens when someone tries the wrist, which is a bad design for a bracelet and a good reason not to make one.

## Notes

The teens’ theft was not caught by this thread. Pim’s knowing came from the shelf, not from a night alarm. Do not retcon the thread into the lock.
