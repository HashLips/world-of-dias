# Deb-Gate Threshold Thread

## Name

Deb-Gate Threshold Thread

## Overview

A **Deb-Gate Threshold Thread** is a thin touch-line strung at ankle height so arrivals feel the threshold before clerks speak. Dignity craft: notice the body crossing before the paper does.

## Description

Often ivy-dyed; geese hate when it is missing. Touch symbol cousins hang nearby. Not a tripwire weapon—cutting it for “efficiency” is Forced-Final manners and gets you hissed.

## Cultural Meaning

Body-first clearance. Softfruit likes it; some Houses call it sentimental and still duck under it.

## Usage

Strung by Deb Gate keepers each dawn; repaired after Flagweek crowds; taught to children as “feel before stamp.”

## Notes

Symbol cousin: Deb Gate Touch. Rule: Deb Gate Threshold Dignity Rule.
