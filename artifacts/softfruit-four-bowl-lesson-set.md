# Softfruit Four-Bowl Lesson Set

## Name

Softfruit Four-Bowl Lesson Set

## Overview

Four nested bowls used at Softfruit tables to teach world / realm / region / phenomenon by taste and steam rather than stamp.

## Description

World-water (clear), realm-tea (tinted), region-fruit (sliced), phenomenon-steam (a warm empty that still smells of peel). The set travels in a cloth with Nest Mark embroidery. Mentors refuse to let children drink the steam bowl—joke first, then lesson: *you do not swallow an event; you notice it.*

## Cultural Meaning

Hospitality as cosmology. If you can laugh and sort, you are ready to walk roads without inventing ferries.

## Usage

Ladle-court lessons; traveler orientation; quiet corrections when someone calls bleed a district.

## Notes

Not a Resonant Artifact of power. A Resonant Artifact of manners, if anything.
