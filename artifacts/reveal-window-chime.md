# Reveal Window Chime

## Name

Reveal Window Chime

## Overview

A **Reveal Window Chime** sounds once when a ledge window opens and once, softer, when it closes. Veil Scribe hardware for anti-stare manners. The second note is the more important one. It is the ledge asking for its clarity back, and the chime’s job is to make that ask audible so talent cannot pretend it did not hear.

## Description

Thin glass-metal tubes on a slate bar, cool, short, unromantic. No swell, no choir, nothing a lingerer can hide inside. Apprentices learn to pack tools at the soft close the way other apprentices learn not to leave a blade in a bench: the packing is respect for the next minute, including their own eyes. A chime that someone has tuned sweeter, more pleading, more likely to be ignored as music, is a chime the guild retunes until it is merely information again. The first note tastes, people say, like cold water. The second note tastes like stopping.

## Cultural Meaning

Brief clarity is a gift. Linger is how opacity bites. The chime is not a truth-compulsion device and does not ring when a liar enters. It rings for structure’s visiting hours. Timers face the chime rather than the view because the view is the temptation and the chime is the job. Visitors who thank a Timer for ending a miracle are thanking the culture this object enforces.

## Usage

Window shelves, phase benches, and, as metaphor loans, visitor queues where some other clarity has a bad habit of overstaying. The loan must not teach anyone that a chime elsewhere reveals souls. It teaches ending.

## Notes

Reveal windows are not lie detectors. The chime is a clock with two words: open, close.
