# Toll Talk Token

## Overview

A **Toll Talk Token** buys the right to ask one hard question at a supervised crossing—metered truth in chalk weather.

## Description

Notched wood or stamped scrap; valid for one marshal-answered query (route risk, stamp authenticity, convoy warning). Labor-rest payers sometimes earn a token instead of coin change.

## Cultural Meaning

Ansa’s “never a shrug” extended to speech. Nessa Tolltalk issues them like medicine—dose-limited.

## Usage

Plot engine: token spent on the wrong question; or refused when the true answer would start a riot.

## Notes

Communication artifact. Chapter starter: a child holds a token and asks about Long Gate.
