# Socks

## Name

Socks

## Overview

**Socks** is Sorel cover craft: a pale foot-garment dense with vibrant red circles and a thick red zigzag cuff, shown on a bright cyan limb in plates—pull-on finished when the zigzag sits true.

## Description

Sorel makers keep the circle pattern even and the zigzag sharp; a soft cuff without the zigzag is considered unfinished in careful houses. Cyan limb in the plate is the telling contrast, not a dye rule for every wearer. Local care forbids wearing a torn zigzag into a guest hall as if complete, and forbids mocking the dots as childish. Resonance is red pattern on pale; memory is the cuff rhythm; wonder is slate quiet around such loud cover. Pairs return clean. Soft talk that treats Socks as empty fashion fluff misses Sorel's rule: the zigzag seals the cover.

## Cultural Meaning

In Sorel, socks means a dotted cover sealed by a zigzag cuff.

## Usage

Daily cover and guest readiness. Not a joke prop.
