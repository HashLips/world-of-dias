# Decorate

## Name

Decorate

## Overview

**Decorate** is a kept Claimscar Yard ornament set: a golden pitcher painted with cobalt flowers and a single black jagged bloom-stem used to teach that table prettying must still carry weight honestly.

## Description

The pitcher is bulbous gold with blue six-petal marks, sized for a guest table. The stem is thin on purpose so the heavy black multi-point bloom cannot be ignored—it droops, and that droop is the lesson. Set on a pale blue thin-legged table cloth or board. Yard hosts place it when celebrations risk becoming cover for unmentioned scar. Removing the black bloom to make the arrangement “nicer” is the emptied craft the plate warns against. The set is lent for cookfire and secondfire gatherings more than sold.

## Cultural Meaning

Claimscar Yard likes beauty that does not erase claim-scar memory.

## Usage

Guest tables, yard festivals, and apology meals. Returned with the black bloom still attached.

## Notes

Honest ornament. Keep the heavy bloom.
