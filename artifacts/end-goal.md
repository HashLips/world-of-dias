# End Goal

## Name

End Goal

## Overview

**End Goal** is a kept F432 threshold kit: a peach path cloth with green dash marks, white side barriers, and a red finish ribbon used before anyone claims a bright yellow goal-orb as private property.

## Description

Hosts roll the path, set barriers, string the red ribbon on thin posts, and place a yellow disc beyond—not to be taken home. Apprentices walk the dashes at agreed pace. Crossing without naming what was finished is bad craft. Frequency talk treats the smile-arcs in the plate as watchfulness of the realm, not a creed to worship. Selling the yellow disc as a trophy empties the kit.

## Cultural Meaning

F432 likes finishes that leave the bright thing still shared.

## Usage

Journey closings, apprentice completions, and guest thank-you walks. Lent as path-plus-ribbon set.

## Notes

Threshold kit. Cross the red; leave the orb.
