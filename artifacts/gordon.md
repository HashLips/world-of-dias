# Gordon

## Name

Gordon

## Overview

**Gordon** is a kept F432 named pause vessel: a tall purple cup with a thin black straw and a mustard collar-token used when a watch needs an ordinary sip-break that still counts as care.

## Description

The purple vessel is tapered and opaque-dark when filled; the straw is thin so sips stay slow. A mustard collar band or card sits beside as “work still worn, rest allowed.” Frequency hosts call the set **Gordon** so the break has a name and cannot be shamed as laziness. Selling it as novelty without the slow-sip rule empties the craft. Portrait plates remind that pink pause-forms are neighbors, not mascots.

## Cultural Meaning

F432 treats named rest as part of honest watching.

## Usage

Night watches, apprentice shifts, and guest decompression. Lent with vessel washable and straw replaceable.

## Notes

Named pause vessel. Sip slow; keep the watch kind.
