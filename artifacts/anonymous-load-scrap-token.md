# Anonymous Load Scrap Token

## Name

Anonymous Load Scrap Token

## Overview

An **Anonymous Load Scrap Token** is the unlabeled chip **Kesh Lineborn** (and couriers like him) leave with scrap jobs: Operator-adjacent help without an Operator signature. It lets Orrin receive load curves and conduit notes without being cleared—or accused.

## Description

A dull resin or soft-metal chip, often warm from a pocket, sometimes with a faint load-fan scratch on one face. No House stamp. No name. Left in a left-side drop at the **Anonymous Drop Wall**, or tucked under a tea cylinder when the courier will not stay for thanks.

The token does not grant passage through core slots. It means: *this scrap is intentional; do not file the courier; treat the paper as noise unless it walks.*

## Cultural Meaning

Operator adjacency without admission. For Orrin it is oxygen and insult at once—useful graphs wrapped in the same manners that file wonder as noise. After escape, some tokens arrive humming wrong; Kesh does not explain.

## Usage

Carried with scrap bundles; returned or destroyed after a job; never sold openly (Null buyers offer coin; honest couriers refuse). Appears in Movement One when Orrin learns what Operators call noise.
