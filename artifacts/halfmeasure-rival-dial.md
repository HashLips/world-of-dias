# Halfmeasure Rival Dial

## Name

Halfmeasure Rival Dial

## Overview

**Noro Halfmeasure**’s proudly over-precise calibration dial—the rival craft object that still misses mischief. It can split a tick finer than Orrin’s chalk, and still fail to catch the Caliburn’s half-digit lies until Noro is forced to admit them.

## Description

Heavy face, ceremonial polish, hairline graduations Noro boasts about in tea-cylinder arguments. Brought to the alcove to “correct” Orrin’s Frame runs. Early in the saga it proves F432 home-line stability better than Orrin’s loupe; later it settles into helpful agreement and wakes wrong by half a digit—the same cyan weather as the Frame.

Noro’s arc is partly this object’s arc: mock → admit → carry the vault latch anyway. The dial remains in Noro’s kit; it is not left as a trophy in Orrin’s alcove.

## Cultural Meaning

Rivalry as care. Over-precision is not the same as honesty. Row apprentices learn both men’s tools: crooked chalk and proud dial.

## Usage

Bench calibration; argument prop; teaching example that fine graduations do not immunize against Echoform almost-agreement.
