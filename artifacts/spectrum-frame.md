# Spectrum Frame

## Name

Spectrum Frame

## Overview

The **Spectrum Frame** is Orrin Veld’s triumph instrument: a lattice of tuned glass, filament, and chalk-ruled apertures built to **graph background-band signatures from inside F432** without claiming a subway between realms. It became the first nest of **the Caliburn**, then a deliberately incomplete teaching tool after the Echoform escaped.

## Description

A standing rectangular frame about shoulder-high in the **Veld Workshop Alcove**. Edges wrapped in waxed cord. Inner plane a layered “window” of thin instrument glass etched with measure-marks. Heel-cap contact plates on the base pick up floor hum so graphs can be checked against building load. Side spools feed calibration filament; Mio’s folding chalk rule sets aperture ticks.

**What it does (plain):** when powered for a run, the glass shows stacked faint bands—home **F432** as a steady middle line, with ghost signatures Orrin argued matched **F120**, **F380**, **F610**, **F840**, and (disputed) **F960**. It does not open doors. It makes rumor bands graphable beside Softfruit folk data and the Supplemental Harmonic Ledger Leaf’s claims.

**What went wrong:** after high-precision runs, a **residual calibration seam** lingered—brightness past polite window length. The Caliburn nested in that persistence (amber helpfulness, then cyan lies). Vault attempts cracked one upright and blackened a corner spool. The Frame no longer hosts the Echoform openly; Orrin keeps filament paths and one aperture **incomplete on purpose** so students learn partial truth, not widen-hunger.

## Cultural Meaning

On the Row it is pride and cautionary tale: precision is not free. Houses want it stamped. Operators want it forgotten. Softfruit vendors ask if it can tell whether fruit will keep. Schools later use small incomplete teaching models inspired by it—not the original.

## Usage

- Built for reproducible cross-band signature graphs.
- After escape: teaching partial spectrum honesty only—never “one more widen.”
- Not reused as a vault; the failed latch stays a separate warning object.
