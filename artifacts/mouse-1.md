# Mouse

## Name

Mouse

## Overview

**Mouse** is an Averra Isle studio cue: a white snout face-mark with pink tongue and blue brow arches hung or worn when a maker is mid taste-check of air, plaster, or pigment, used so others pause before offering tools.

## Description

Marks clip to aprons or hang above benches. Pink tongue piece flips up when active. Children learn the pause game. Adults who shove a brush past an active tongue redo the taste-check aloud. Red shoulder cloth optional for plate matching.

## Cultural Meaning

On Averra Isle, Mouse is sensory manners. Resonance favors waited tongues. Using the mark to stall work forever empties it into laziness jokes that still respect the pause once.

## Usage

Damp studios, pigment benches, and teaching rooms. Marks wiped; tongues flipped down after.

## Notes

Culture- and religion-agnostic. Matches snout taste plate.
