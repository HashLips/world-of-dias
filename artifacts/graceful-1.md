# Graceful

## Name

Graceful

## Overview

**Graceful** is a kept F500 composure token: a periwinkle reclining form card used at cream-orange seam rooms so apprentices practice soft stillness without staging fragility for sympathy.

## Description

The card shows the black-lined periwinkle sitter at the vertical color split. Hosts place it when a room needs quiet without collapse. Frequency talk forbids reading the blue body as an Earth race or costume. The lesson is posture: tilt, breathe, keep line-weight honest. Selling the token as sad-girl décor empties the craft.

## Cultural Meaning

F500 likes grace that can still stand up afterward.

## Usage

Quiet rooms, guest decompression, and apprentice pause drills. Lent and returned unbent.

## Notes

Composure token. Soft; not collapsed.
