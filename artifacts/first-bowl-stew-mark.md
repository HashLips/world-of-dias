# First-Bowl Stew Mark

## Name

First-Bowl Stew Mark

## Overview

A **First-Bowl Stew Mark** is a wooden chip dropped in the hall pot to claim the shelter-first bowl before coin talk. Joy and survival sharing the same ladle weather.

## Description

Onion-stained; carved with a simple hearth tick. Guests without marks still eat—the chip is for order, not exclusion. Selling marks as VIP tickets gets you kitchen exile.

## Cultural Meaning

Shelter before ledger. Softfruit cousins nod approvingly.

## Usage

First-Bowl Hall cooks; storm nights; laughter week demos for children.

## Notes

Place: Hearthvale First-Bowl Hall.
