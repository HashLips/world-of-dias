# Id of Mine

## Name

Id of Mine

## Overview

**Id of Mine** is a Veloria City portrait-tile set: cream-framed blue bust plates with charcoal caps and cyan ties, stored in black registry racks, used when a role looks identical and the living name must still be spoken aloud.

## Description

Tiles are uniform on purpose—same blue face-treatment, same glowing cyan tie as role signal. Caps sit charcoal and slightly askew. Racks hold them in tight grids like the plate. Clerks training at the Stamp Gallery practice pulling a random tile and naming a real person before stamping anything. Visitors sometimes mistake the set for one person copied forever; locals correct them: the sameness is the job-clothes of the image, not proof that memory is blank. Damaged cyan ink on a tie means the tile needs remaking before it returns to the rack.

## Cultural Meaning

Around Veloria City, Id of Mine is a humility tool against lazy sorting. Resonance favors the clerk who slows for a name. Treating the grid as a joke about nobodies is considered a cold echo.

## Usage

Registry drills, gallery lessons, and careful replacements when a tile fades. Not worn as jewelry.

## Notes

Culture- and religion-agnostic. Matches the repeated portrait grid.
