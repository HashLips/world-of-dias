# Long Gate Courtesy Knot

## Name

Long Gate Courtesy Knot

## Overview

A **Long Gate Courtesy Knot** is a short cord tied to carts and exile packs at the Long Gate to show the holder will yield once for dignity before arguing stamps. Travel manners object, not a free pass.

## Description

Hemp-and-ribbon twist in Nauw/Sorel colors; loosened after the first courteous yield. Selling “skip-the-gate knots” is a known scam; Softfruit vendors cut false knots publicly.

## Cultural Meaning

Threshold dignity made portable. The knot remembers the argument without settling Frequency politics.

## Usage

Tied by gate stewards and Brindle line-ox drivers; checked before Forced-Final clearance speeches.

## Notes

Place: Long Gate. Holders: crossing stewards, exile families, fruit-road crews.
